# Goal147 结果：终端 pitch gain 是瓶颈，K4 把 C1 dev40 从 26/40 提到 40/40

**预注册**：`goal147_c1_terminal_pitch_authority_20261111.md`<br>
**性质**：固定 `C1_000300000` 做 dev40 eval-only；未训练、未改 reward/terminal/success/goal radius，未打开 held-out。

## 1. 结论

```text
B85/B75 终端减速无效，success 25/40、23/40，低于 Z 的 26/40
K4（base_controller.pitch_gain 2 -> 4）dev40 40/40，plane miss 0
K4 的 7 个 1.25–1.5 m 失败全部转化，额外 gain 14、loss 0
K4 policy 与 zero-command-residual 都是 40/40，逐项几乎相同
K4 400k guard 也是 policy/zero 40/40，eta_done 1.2347/1.2366 m
R2（pitch_rate_gain 2x）崩到 11/40，pitch 目标更陡但实际跟不上
```

因此本 Goal 的裁决是：

```text
K4_PASS_EVAL_ONLY
CONTROLLER_PITCH_GAIN_BOTTLENECK
POLICY_ZERO_PARITY
```

这不是神经网络收益。K4 是**传统基座控制器参数修复**：它让 stern 更早、更强地跟踪
terminal pitch 目标，从而在 2 m 前建立足够的纵向速度/姿态。当前 PPO residual 只有
`1.5e-4` 量级，policy 与 zero 没有可区分差异，不能写成“PPO 学会了终端捕获”。

## 4. 机制

### 4.1 减速给了时间，但横向先崩

B85/B75 的 failure final vertical 从 `1.546 m` 降到 `1.485/1.460 m`，说明减速确实
让 pitch loop 多了一点时间；但 final horizontal 从 `0.281 m` 升到
`0.356/0.432 m`，plane miss 从 14 升到 15/17，净 success 反而下降。近终点失败
`0/7` 转化。结论是：**terminal slowdown 不是有效杠杆**。

### 4.2 K4 是有效杠杆：pitch 增益翻倍让 terminal capture 提前成立

| arm | success stern sat <=3m | failure stern sat <=3m | failure `|stern|`@2m | failure `|target pitch|`@2m | failure `|actual pitch|`@2m |
|---|---:|---:|---:|---:|---:|
| Z | `0.086` | `0.434` | `0.317 rad` | `0.782 rad` | `0.289 rad` |
| K4 | `0.012` | `NA` | `NA` | `NA` | `NA` |
| R2 | `0.189` | `0.681` | `0.331 rad` | `0.986 rad` | `0.359 rad` |

K4 的成功组 stern 饱和率只有 `0.012`，远低于 Z 成功组的 `0.086`：它不需要把 stern
顶到极限，而是在更早的距离就用更高的 pitch 跟踪把轨迹带到 terminal corridor 内。
这与 Goal146 的判读一致：瓶颈不是 rate limiter，而是 pitch loop 对目标的跟踪增益。

### 4.3 R2 说明“提高 rate gain”不是同一条路

R2 把 pitch 目标推到 `0.986 rad`、failure stern 饱和到 `0.681`，但 actual pitch 只有
`0.359 rad`，success 崩到 `11/40`。在相同 terminal 几何下，单纯放大 rate gain 会让
目标更陡、饱和更高，却没有改善实际跟踪。K4 与 R2 的差异支持“角度环增益”而不是
“速率环增益”是当前可用的修复点；但这只是 dev40 的单点证据，不外推到其他场景。

### 4.4 policy 与 zero 完全同向

K4 policy 的 command residual 平均绝对值约 `1.45e-4`，zero 为 `0`；两者 success、
plane miss、eta_done、overshoot 全部相同（`40/40`、`0`、`1.2349/1.2366 m`、`0`）。
因此 K4 的收益全部来自 controller，不是 residual。不能在 Goal148 之前把 K4 写成
“神经网络终于打赢传统方法”。

1. 固定 `C1_000300000` + K4 controller，在 `nominal / current15 / current20 /
