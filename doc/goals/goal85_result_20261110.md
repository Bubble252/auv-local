## 1. 结论

Goal85 的位置契约已经生效：

```text
training observation:  p_nav = eta + zero-mean noise
reward / termination:  eta
official success:      eta_tight_at_done
diagnostic:            p_nav distance
```

10 万步 sensor audit 和 20-run / 800-episode eval-only 矩阵都完成。没有训练、没有
打开 held-out、没有换算法、没有改 reward/action/checkpoint 规则。

结论分三层：

1. **位置契约 PASS**：`p_nav - eta` 均值绝对值最大 `1.44e-4 m`，首尾窗口漂移最大
   `2.16e-4 m`，所有 sensor delay `0`，`nav_age_max_s=0`。
2. **原 Gate 的 done-frame success gap 不可识别**：endpoint-stop 把成功 episode 的
   `eta` 截断在半径边缘（default `1.985 m`、strict125 `1.236 m`），零均值 `p_nav`
   噪声会让约 `47–53%` 的成功样本落到球外。该 success gap 不能当作 frame residual。
3. **censoring-safe 的 done-frame 距离偏差 PASS**：`mean(p_nav_done - eta_done)` 为
   `+0.0157 m`，95% CI `[+0.0009, +0.0299] m`，远小于 `0.05 m`。Goal84 的
   `-20.6 pp` 系统性 frame gap 已消失。

**学习残差的效果仍然是负的。** 在同一个 ALOS + PD/PI 链上，4 个 frozen Goal59
checkpoint 相对 zero-residual 的 `eta_tight_at_done` 配对差值为：

| 场景 / root | Δ eta_done | 95% CI | Δ path RMSE |
|---|---:|---|---:|
| default / baseline | `-13.13 pp` | `[-22.50, -4.37] pp` | `+0.0218 m` |
| default / candidate | `-2.50 pp` | `[-11.25, +6.25] pp` | `+0.0233 m` |
| strict125 / baseline | `-9.38 pp` | `[-16.88, -1.87] pp` | `+0.0254 m` |
| strict125 / candidate | `-10.63 pp` | `[-19.38, -2.48] pp` | `+0.0263 m` |

timeout 和 safety 都是 `0`；plane-miss 的上升幅度与 eta_done 的下降幅度相同。
因此当前失败不是“残差太小”，而是**残差非零但在终端把好轨迹推坏**。

## 6. Frame gap 判读

原预注册 Gate 行是：

```text
eta_done vs p_nav_done paired gap 95% CI 包含 0，且无稳定负方向
```

本轮得到 `p_nav_done - eta_done = -24.88 pp`，CI `[-31.00, -18.63] pp`。但审计显示
这不是系统偏差：

- done 帧 `mean(p_nav - eta) = +0.0157 m`，CI `[+0.0009, +0.0299] m`；
- `std(p_nav - eta) = 0.133–0.148 m`；
- 成功 episode 的 `eta_done` 距离正好在边界内：default `1.985 m`、strict125
  `1.236 m`；
- 在 `eta_done=true` 的样本中，`47.2–52.9%` 的 `p_nav` 落在球外；
- 在 `eta_done=false` 的样本中，只有 `0–8.7%` 的 `p_nav` 落在球内。

这是 endpoint-stop censoring 造成的选择效应。把同一 Gate 写成 success-rate gap
在数学上不可识别；**不能据此判 `FRAME_RESIDUAL`，也不能据此改算法**。

判定：

```text
contract checks                    PASS
original success-gap criterion     INVALID_METRIC (censoring)
censoring-safe distance bias       PASS
learned residual effect            NEGATIVE
```

## 7. 对“神经网络打不过传统方法”的含义

Goal85 给出了一个更干净的对照：去掉 `p_nav` bias/delay 后，zero-residual 的
eta_done 在 default 为 `65.5–77.0%`、strict125 为 `26.5–42.5%`；学习残差没有提高，
反而下降。这个结果说明：

- 不是 NoisyNet 主导；
- 不是 `p_nav` bias/delay 主导；
- 不是残差太小或饱和；
- 当前 frozen DDPG/TD3-style 残差在 nominal 下确实伤害终端捕获。

因此下一步不应继续扫这个残差的 scale/seed，也不应直接开 SAC。应先执行强制的
Goal85b plant mismatch，确认模型失配下是否有不同结论；然后进入 Goal86，用
BC 先验、PPO/SAC 和传统控制器 + RL 残差做同协议对照。Goal86 的 Step 0 必须先
审计 SAC PC residual 适配器，smoke 不过就标 `SAC_ADAPTER_INVALID`。
