# Goal26 最终结果：success-first residual PPO screen

日期：2026-11-08<br>
总体裁决：**FAIL / STOP**

## 1. 结论

在 frozen D3 BC 上学习 action residual，并用小权重 3D path reward 做 PPO：

- 两档预注册路径奖励都通过了 success/safety/plane-miss/timeout 护栏；
- 两档都没有通过效果门禁；
- pre-goal 3D RMSE 只改善约 `0.014–0.017 m`，远低于 `0.10 m` 门槛；
- success 没有提升，P1 两场景各下降 `0.025`，P2 default 持平、strict125 下降 `0.025`；
- 按预注册预算，停止，不扩训练 seed，不扫第三档权重，不启动 3-seed 正式训练。

这次结果不是“趋势向好”，而是明确的负结果：action residual + path reward 在当前
架构和预算下没有产生可用的路径跟踪收益。
