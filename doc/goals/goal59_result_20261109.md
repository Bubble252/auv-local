## 1. 结论

Goal59 的预注册 Gate **FAIL**：`0/8` 个 formal seed 通过全部检查，8 个 seed 的
deterministic 和 actor raw saturation 都为 `100%`。softsign + scale `0.5` 没有在
5M formal 训练后维持有界性，只是把 tanh 的边界换成了 softsign 的高幅值边界。

两个 seed（`752/880`）在 strict125 上出现恰好 `+0.05` 的 terminal capture
改善，但 default 没有改善，同时 success 下降、plane-miss 上升，且 action
saturation 约 `1.0`，因此不满足主效果加护栏，也不能写成 PASS。对这两个 seed
跑 default `path-zero` 后 capture/plane/RMSE 基本不变，按协议记为
`INVALID_ATTRIBUTION`，不能声称 12D endpoint context 产生了效应。

NoisyNet 不是全局主因：8/8 的 deterministic mean 已经饱和；`noise/det` 中位数
只有 `0.019`，只有 seed `1008` 的 `noise/det≈1.03`、`noise>det≈0.66`。即使
seed `1008` 的噪声更明显，其 deterministic raw saturation 仍是 `1.0`，闭环指标
也没有改善。

## 4. 残差与 NoisyNet 审计

正式 probe 使用每个训练 seed 的 `final.pt`、训练 seed 段、直到 episode 终止

聚合：

- `noise/det` 中位数 `0.0193`，均值 `0.2029`；
- `noise>det` 中位数 `0`，只有 seed `1008` 达到 `0.660`；
- hidden sigma `0.3003–0.3006`，output sigma `0.0998–0.1004`，仍在初始化附近；
- 8/8 deterministic saturation 和 raw saturation 都是 `1.0`；
- gate-active residual L2 为 `10.5%–22.5%`，说明残差不是“太小”，而是太大且方向不受终端目标约束。

### 4.1 为什么这次不是 NoisyNet 主导

训练日志的 stochastic residual 会被噪声放大，但正式评估使用 deterministic mean
weights。当前 8/8 的 mean 已经贴着 softsign 边界，且 sigma 没有膨胀；除 seed
`1008` 外，`noise>det` 都是 `0`。seed `1008` 的噪声比例较高，但它的 mean 仍
100% 饱和，闭环 success/plane-miss 也变差，因此不能把整体失败归因于噪声头。

这与 Goal58 的旧结论一致：NoisyNet 会影响探索，但不能解释 deterministic 策略的
边界饱和。关闭 NoisyNet、缩小噪声或改用 eval-time scale 都不是本 Gate 的修复。

## 8. 决策与下一步

决策：`pivot`。停止 softsign/gated command-residual 参数化主线，不用关闭
NoisyNet、不换 seed、不增加预算、不放宽阈值来救 PASS。

不启动 SAC/REDQ/DroQ：当前失败不是“残差小、优化不足”，而是 residual 饱和且
闭环方向错误；换算法不能替代动作参数化、reward 和 terminal capture 的修复。

下一 Goal 应先做预注册的只读诊断：

1. 动作参数化：softsign raw 边界、output scale、rate clip、gate 时序和
   deterministic saturation 的关系；
2. reward：dense path 项、goal-plane miss、terminal progress 与真实 terminal
   capture 的方向是否一致；
3. terminal capture：终止平面、终端观测、true-state capture 和 protocol success
   的口径是否对齐；
4. 只有在诊断明确显示优化/探索不足时，才另开 SAC 同协议对照；只有明确显示样本
   效率不足时，才考虑 REDQ/DroQ。

held-out `100–149` 继续关闭；本 Goal 不自动 commit/push。
