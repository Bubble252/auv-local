## 1. 结论

Goal40 用 Goal38 四个 fresh block 的全部 40 个 dev seeds，分别检查了 terminal
plane miss 的 horizontal/vertical 分量，以及 protocol `success` 与 true-`eta`
terminal capture 的一致性。冻结映射给出：

```text
H-VERTICAL-CONCENTRATION = PARTIAL
H-PNAV-ETA-DISCORDANCE   = SUPPORTED
overall                  = PROTOCOL_ETA_DISCORDANCE_SUPPORTED
```

最关键的结果不是候选策略是否更好，而是评测语义：四个 block 中都有大量 episode
被 environment 记为 `success`，但真实 `eta` 并未进入 goal capture 半径。

| scenario | mode | protocol success | success without eta capture | fraction |
|---|---|---:|---:|---:|
| default | baseline | 29 | 13 | `0.4483` |
| default | candidate | 28 | 12 | `0.4286` |
| strict125 | baseline | 20 | 13 | `0.6500` |
| strict125 | candidate | 19 | 7 | `0.3684` |

因此，后续不能只用 `success` 宣称 true-state terminal capture 成功；protocol
success 与 `goal_capture_eta` 必须同时报告。

## 3. Plane miss 分量

| scenario | mode | plane miss n | vertical dominant | vertical fraction | horizontal fraction |
|---|---|---:|---:|---:|---:|
| default | baseline | 11 | 10 | `0.9091` | `0.0909` |
| default | candidate | 12 | 4 | `0.3333` | `0.6667` |
| strict125 | baseline | 20 | 17 | `0.8500` | `0.1500` |
| strict125 | candidate | 21 | 10 | `0.4762` | `0.5238` |

baseline 的两个 block 都以 vertical 分量为主，但 candidate 的两个 block 都不满足
`0.60` 阈值；default candidate 已明显转为 horizontal 主导，strict125 candidate
则接近均分。因此 H-VERTICAL-CONCENTRATION 只能判为 `PARTIAL`（`2/4` blocks），
不能把修正后的全部 terminal miss 继续归为 vertical。

候选策略没有提高 protocol success，但改变了失败几何。这是一个描述性发现，本 Goal
没有预注册 candidate-vs-baseline 机制 Gate，不能据此宣称候选改善了控制。

## 4. Protocol/eta discordance

所有四个 block 的 `success without eta capture / protocol success` 都超过预注册的
`0.30` 阈值，因此 H-PNAV-ETA-DISCORDANCE 为 `SUPPORTED`（`4/4` blocks）。

反向 discordance `eta_capture and not protocol_success` 只出现在 strict125
baseline，共 1 个 seed；其余三个 block 为 0。它不是本 Goal 的主假设，但说明两个
terminal 定义并不互为简单子集。

`p_nav` protocol success 掩盖 true-`eta` miss 的现象在 default 和 strict125、
baseline 和 candidate 中同向存在，因此不是单个 scenario 或单个 arm 的偶然现象。

## 5. 假设裁决

```text
H-VERTICAL-CONCENTRATION = PARTIAL
H-PNAV-ETA-DISCORDANCE   = SUPPORTED
overall                  = PROTOCOL_ETA_DISCORDANCE_SUPPORTED
```

本裁决不允许把 `PARTIAL` 升级为 `SUPPORTED`，也不允许把 protocol success 当作
true-state terminal capture。Goal39 的 `INVALID_DIAGNOSTIC` 仍然有效；Goal40 只是
换用了不依赖 vertical-miss 最小样本量的全 seed 问题。
