# Goal89 结果：旧 gate-scope 训练臂无效，网络结构与接口契约已澄清

**日期**：2026-11-11<br>
**状态**：`INVALID_GATE_SCOPE / NETWORK_PARITY_OK / PIVOT_TO_GOAL90`<br>
**上游**：Goal89 protocol、Goal88 S1.25、Goal86 P-A BC<br>
**性质**：结果归档与失败归因；不打开 held-out，不改 reward/terminal/success/goal radius。

## 1. 结论

Goal89 的旧 `G20_5/G10_3` 训练臂不能用于 Gate，原因是 gate scope 错误，不是网络结构
错误：

```text
旧训练：ALOS + scale * gate * (r_BC + r_PPO)
旧评估：ALOS + scale * (r_BC + gate * r_PPO)
```

远离 goal 时旧训练把 `r_BC` 一起关掉，退化成纯 ALOS，因此 success 从 BC 的
`31/40, 20/40` 掉到 `23/40, 14/40`。这些 arm 统一标记为
`INVALID_GATE_SCOPE`。

`goal89_v2` 的 absolute 实验则属于 `INVALID_WRONG_BC_CHECKPOINT_CONTRACT`：
Goal86 P-A checkpoint 的 `r_BC` 是执行器残差，不是绝对动作。

## 2. 有效诊断

在正确理解 checkpoint 语义后，Step 7 的 `policy` vs `frozen-base` 配对得到：

- 旧 Goal89 12 组配对中，success 全部相同；
- Goal88 S1.25 无 gate：BC1.25 strict125 `19/19/19`，
  PPO policy `20/20/19`，仅 `+2/120`；
- PPO 同时把 path 拉差约 `0.017–0.036 m`。

因此 Goal88 的主要收益来自 BC 残差放大到 1.25，而不是 PPO 学到了有效终端策略。
网络结构与权重对齐见
`doc/goals/goal89_network_parity_and_gate_scope_audit_20261111.md`。

## 3. 处置

- 旧 Goal89 训练臂：`INVALID_GATE_SCOPE`，不进入 formal；
- 旧 absolute arm：`INVALID_WRONG_BC_CHECKPOINT_CONTRACT`，不进入 formal；
- 保留 `P-A` checkpoint 的残差语义：
  `r_BC = normalize(D3_actuator - ALOS_actuator)`；
- 新开 Goal90，把 gate 只作用在 `r_PPO`：
  `ALOS + 1.25 * (r_BC + gate_10_3 * r_PPO)`。

## 4. 后续结果

Goal90 已验证 corrected gate：default `31/31/31`、strict125 `20/20/19`、
path 相对 BC 约 `-0.0004 m`。Goal91 进一步证伪了“低噪声是主瓶颈”。
因此 Goal89 自身没有 formal PASS/FAIL，只产生一次预注册 pivot。
