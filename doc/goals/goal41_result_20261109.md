## 1. 结论

Goal41 只审计 Goal40 的 discordant subgroup：

```text
discordant = summary.success and not summary.goal_capture_eta
```

四个 block 的 45 个 discordant seeds 中，`p_nav` 比 true `eta` 更接近 goal 的
比例均为 `1.0000`，估计误差方向指向 goal 的比例也均为 `1.0000`。冻结映射给出：

```text
H-NAV-DISTANCE-BIAS  = SUPPORTED
H-NAV-DIRECTION-BIAS = SUPPORTED
overall              = NAV_BIAS_MECHANISM_SUPPORTED
```

这不是“候选策略已经成功”的结论。它说明 protocol success 与 true-`eta` capture
的差异有明确 terminal nav-bias 机制：在 discordant seeds 中，估计位置被系统性拉向
goal；因此后续允许预注册 estimator calibration/nav-age 审计，但不允许训练或修改
控制器。

protocol termination 中的任何一个单因素。
