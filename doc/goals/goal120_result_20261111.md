## 4. 一个必须记录的测量问题

`normalize_advantage_per_mini_batch=true` 会把每个 mini-batch 的 advantage
标准化到零均值、单位方差。此时

```text
surrogate_loss = mean(-advantage * ratio)
```

在 `ratio ≈ 1` 时近似等于 `-mean(advantage) ≈ 0`。因此 P1/P3 的
`surrogate ≈ 1e-4` 是归一化的构造结果，**不能**解释为“策略梯度为零”。
本次 Gate 仍按预注册保留 `surrogate` 条件，但实际判读以 `approx_kl` 为主：

```text
max approx_kl = 2.22e-4 < 1e-3
```

所以 `PPO_OPTIMIZATION_LIMITED` 的结论不依赖 surrogate 这个失效指标。
后续 Goal 若继续用 normalized advantage，必须把 `mean(|advantage| * |ratio-1|)`
或 explained variance 作为策略更新强度指标，而不是原始 surrogate。

guidance heading/pitch rate clipping 仍有 73%–88%，但历史 Goal103 已证明


按用户规则“残差很大但闭环不动，不要换算法，先查动作参数化、reward 和
terminal capture”，本 Goal 不直接开 SAC。reward 已在 Goal119 检查，
terminal capture 已在 Goal117/118/103 检查；剩下最便宜、最可证伪的是
**动作权限注入实验**：

```text
decision = continue
next = Goal121 eval-only action-authority injection
```

Goal121 将对同一 B20 base 注入 `zero / ±PPO / 2x / 4x PPO / 常量
rudder/stern/rpm`，测量 reachable failure 的终态 eta 和 success 翻转：

- 若 4x PPO 或常量 residual 能让终态 eta 移动 > 0.25 m，说明动作权限存在，
  PPO 只是没学对方向/信用 → 才值得预注册 SAC 同协议对照；
- 若所有注入都 < 0.05 m，说明 residual 通道在该闭环里近乎惰性 → 先修动作
  参数化/终端几何，不换算法；
- 若 `neg-PPO` 比 `PPO` 更好，说明方向/奖励符号有问题 → 先查 reward/terminal，
  不换算法。
