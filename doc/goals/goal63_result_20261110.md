## 1. 结论

Goal63 在 frozen Goal59 checkpoint 上做了 eval-only 闭环终止抑制：GOAL 半径从
`r0` 收紧到 `r0-0.25 m`，plane-miss guard 保持原 `r0`。baseline 复用 Goal60
trace，candidate 重新 rollout；policy 与 forced zero-residual 都按同一 dev
`20–59` 配对。

结果不是全域 PASS，也不是全域 FAIL：

- default policy 主效果通过：false-success removal `0.621`，true retention
  `0.907`，4/4 checkpoint 通过；
- strict125 policy 的 false-success removal 为 `0.611`，但 true retention 只有
  `0.739`，0/4 checkpoint 通过；
- zero-residual 只在 strict125 方向通过；default zero 的 true retention 为
  `0.750`；
- 因此状态为 `PARTIAL_TERMINAL_SUPPRESSION`。

这支持“default 下终止过早确有一部分 false success”，但不支持把 `0.25 m`
收紧规则直接推广到 strict125。strict125 的 true-capture 损失伴随 plane-miss
上升，下一步应查 terminal geometry/approach，而不是换 SAC/REDQ/DroQ，也不应
在记录后回头调 margin 救 PASS。

## 5. 机制判读

- 两个场景 timeout 都没有增加，safety 也没有增加；
- plane-miss 在 default/strict125 分别增加 `+0.062/+0.088`；
- extra steps 很小（default median `7`，strict125 median `0`），说明大部分
  episode 不是“继续飞很久后捕获”，而是在原球面内很快穿过 goal plane；
- candidate terminal `p_nav` 中位数 default `1.746 m`、strict125 `1.573 m`；
  candidate GOAL 只在 `1.75/1.00 m` 内触发，但不少 episode 在进入更紧半径前
  已经 plane-miss。

这更像 terminal geometry/approach 的限制，而不是 residual 不够大、优化不足或
NoisyNet 主导。Goal59 的 deterministic mean 已经饱和，Goal61 的 zero-residual
也有 p_nav/eta 偏差；本 Goal 又没有训练任何新策略。没有证据支持启动 SAC/REDQ/
DroQ。

## 6. Hypothesis 判定

| hypothesis | 判定 | 说明 |

| H63-A：闭环抑制减少 false success 并保留 true capture | `PARTIAL` | default 支持；strict125 retention `0.739` 失败 |
| H63-B：跨 checkpoint 稳健 | `PARTIAL` | default 4/4；strict125 0/4 |
| H63-C：zero-residual 同向 | `PARTIAL` | strict125 支持；default retention `0.750` 失败 |
| H63-D：失败转向 estimator/geometry | `SUPPORTED_AS_NEXT` | plane-miss 上升、timeout 不增、extra steps 很小 |

## 7. 决策

`decision = pivot`。不改 `0.25 m` margin 重跑本 Gate，不因 strict125 失败换
SAC/REDQ/DroQ，不放宽 retention 阈值，不打开 held-out。

下一 Goal 应先做 terminal geometry/approach 诊断：在 candidate suppression 的
frozen checkpoint 上记录 terminal 前的 plane offset、approach angle、`p_nav`
与 `eta` 距离、residual/动作饱和和 plane-miss 前的时间步；先确认 strict125 的
true success 是在何处、为何丢失，再决定是否需要新的预注册终止规则。
