## 1. 结论

把 C0/C1 的随机 direct command 改成 ALOS 后，C0 从 `0.10` 提升到 `0.85`，
证明 direct-command / frozen-BC 输入错配确实是此前停滞的主因之一；但 `0.85`
仍低于预注册 Gate 的 `0.90`，因此课程没有晋级。

更关键的是，同 checkpoint、同 C0、同 40 个 dev seed 的三组对照：

| arm | 控制/残差 | success | plane miss |
|---|---|---:|---:|
| `policy` | frozen-BC + PPO 残差 | `0.85` | `0.15` |
| `zero-residual` | frozen-BC 基座 + 零 PPO 残差 | `0.85` | `0.15` |
| `alos` | 纯 ALOS，无 frozen-BC | `0.925` | `0.075` |

`policy` 与 `zero-residual` 完全相同，说明当前 PPO 增量没有改变 C0 行为；
真正拖累 C0 的是 frozen-BC 残差基座。纯 ALOS 已经过 `0.90` Gate，因此这不是
课程 sampler、direct command、current alpha、seed 噪声或 Gate 阈值问题。

## 2. 训练与 Gate

- `C-full-alos` 与 `C-no-current-alos` 均从 C0 起跑，1M transitions，dev40。
- 两者在 `100k/200k/300k/400k` 均为 default `0.85`、strict `0.85`、
  plane miss `0.15`、timeout `0.0`、safety `0.0`。
- 300k 连续两次没有提升，判 `CURRICULUM_STALLED`；之后 stage hard-cap 判
  `STAGE_BUDGET_EXHAUSTED`。两条 run 的 `final.pt` 均已落盘，最终仍是 C0。
- 没有 timeout 或 safety，6 个失败全部是 `goal_plane_miss`；最终距离
  `1.38–1.90 m`，C0 `goal_radius_m=1.25`，属于贴边但未进入半径。

## 3. 失败几何

对 300k checkpoint 的失败 seed 21 与成功 seed 20 做同 checkpoint trace：

| seed | 结果 | 跨面水平误差 | 跨面垂直误差 | 总距 |
|---|---|---:|---:|---:|
| 20 | success | `0.64 m` | `0.70 m` | `1.24 m` |
| 21 | plane miss | `1.34 m` | `1.33 m` | `1.89 m` |

失败不是“飞不到目标”或“探索走偏”，而是末段 3D 捕获精度不足。失败集
`actuator_residual_magnitude_clip_rate` 均值约 `0.60`，成功集约 `0.53`；
残差在末段接近/达到执行器限幅，存在动作权限与饱和风险，但不能单独解释
`policy == zero-residual` 这一事实。

## 4. 裁决

本结果**不**支持“换 PPO/SAC 主算法”或“放宽 C0 Gate”。下一步必须：

1. 保留 frozen-BC + PPO 作为原实验组，不覆盖已有结果；
2. 新开 `Goal144`，在纯 ALOS 基座上做 PPO/SAC 残差（命令行 3D command residual
   为主，actuator residual 为对照），同 C0/C1、同 dev40、同 `0.90` Gate；
3. 在该臂中单独审计 terminal capture、残差限幅和末段权限；不改 reward、terminal、
   success、goal radius；
4. 只有 ALOS+RL 仍失败且明确指向优化/探索时，才开 SAC 对照的独立归因 Gate。

Goal140 仍为 `P2`，不得在 Goal143/Goal144 的 C-line 裁决前启动。
