## 3. 路线主指标

所有 `64` 个 policy paired cell 的 `route_absolute` 和 `route_relative` 都是 false。
全矩阵最好的绝对 3D route delta 也只有：

```text
R0_ALOS_SAC strict125 nominal: -0.00245 m
relative gain: 0.138%
improved segments: 1/5
```

Pre-registered H171-A 要求至少一个 arm 在 current10 的 default/strict125 达到：

```text
absolute route delta >= 0.05 m
relative route gain >= 5%
至少 3/5 segments 改善
```

当前差距约两个数量级，不是“差一点”。

### 3.1 current10 的配对结果

## 4. 残差权限诊断

### PPO

`R1_BC_PPO current10` 的 normalized residual 分通道平均绝对值约为：

```text
[2.23e-5, 1.09e-4, 6.56e-4]
```

折算物理残差约为：

```text
[0.039 rad, 0.048 rad, 57.3 rpm]
```

`requested_action` 与 `base_action` 几乎一致。PPO 的确定性残差仍接近零。

### SAC

`R1_BC_SAC current10` 的 learned residual 平均绝对值约为：

```text
[0.00230, 0.00077, 0.00224]
p99 = [0.0307, 0.0146, 0.0409]
```

SAC 的残差明显比 PPO 大，但路线仍然近乎不动。

### 判读

当前没有“noise net 主导”的证据。更符合的解释是：

1. 200k 预算和 8 个 PPO update iteration 不足以形成转向权限；
2. 零初始化的 residual 容易停留在零解附近；
3. reward 改变尚未通过闭环动作产生可测的路线信号；
4. 不能据此直接换算法，也不能直接扩到 5M formal。
