## 1. 结论

Goal42 用同一 checkpoint、configs、dev seeds 和 termination 做了一次确定性的
instrumentation replay，补齐 Goal38 trace 缺失的 `nav_age_s`、`usbl_age_s`、
`dvl_bottom_age_s`、`usbl_valid` 和 `usbl_outlier`。Replay Gate 通过后，按冻结
定义裁决：

```text
H-NAV-AGE-ASSOCIATION   = FALSIFIED  (0/4 blocks)
H-RESIDUAL-CALIBRATION-BIAS = SUPPORTED (4/4 blocks)
overall                 = RESIDUAL_CALIBRATION_BIAS_SUPPORTED
```

结论限定在 Goal40 的 discordant subgroup：terminal nav age 在 discordant 与
non-discordant seeds 之间没有预注册的正向差异；按记录到的 nav age 回看 true state
后，`p_nav` 仍比 lagged `eta` 更靠近 goal。45/45 个 discordant seeds 的 residual
projection 均为正。

因此，Goal41 的 toward-goal bias 不能归因于“discordant seeds 的 nav age 更高”。
本 Goal 支持 residual estimator/calibration bias，但不证明具体 estimator 参数、
USBL gate、nav drift 或 protocol 代码中的哪一个环节造成了 bias。

## 4. Age 修正后的 residual bias

| scenario | mode | median raw projection m | median delay projection m | median residual projection m | residual toward fraction |
|---|---|---:|---:|---:|---:|
| default | baseline | `0.2375` | `-1.6401` | `1.6845` | `1.0000` |
| default | candidate | `0.2158` | `-0.9811` | `1.2906` | `1.0000` |
| strict125 | baseline | `0.1637` | `-0.4114` | `0.6962` | `1.0000` |
| strict125 | candidate | `0.3323` | `-1.8586` | `2.2222` | `1.0000` |

四个 block 中 delay projection 都为负：把 true trajectory 回看到 `t - nav_age`
后，lagged `eta` 反而离 goal 更远。这与“delay/age 让 `p_nav` 显得更接近 goal”的
解释方向相反。扣除该 delay component 后，residual projection 仍为正且更大。

H-RESIDUAL-CALIBRATION-BIAS 为 `SUPPORTED`（`4/4` blocks）；45 个 discordant
seeds 全部满足 `residual_projection_m > 1e-6`。

## 5. 假设裁决与解释边界

```text
H-NAV-AGE-ASSOCIATION       = FALSIFIED
H-RESIDUAL-CALIBRATION-BIAS = SUPPORTED
overall                     = RESIDUAL_CALIBRATION_BIAS_SUPPORTED
```

支持的是“residual calibration/estimator bias 仍存在”，不是“已知 calibration
参数错误”。Goal42 没有修改 estimator，也没有单独干预 nav bias、USBL gain、
delay、OU drift 或 outlier gate；这些都属于后续 read-only 归因。

当前证据不支持把 Goal41 的 toward-goal bias 写成 nav-age 伪影。也不能据此直接
修改控制器：bias 位于 terminal estimator/protocol 语义，控制器修复必须先完成
estimator 单因素归因。

## 8. 限制

- 只有一个固定 checkpoint 和单一训练 seed；本结果不是跨训练 seed 稳定性结论。
- `nav_age_s` 的 age correction 用 true trajectory linear interpolation 近似，
  不能恢复 estimator 内部每次 USBL update 的完整状态。
- H-NAV-AGE-ASSOCIATION 失败只否定本预注册的 terminal age 分组方向，不否定短时
  event、outlier 或 nav drift 在其他时间窗内的作用。
- residual projection 支持“bias 不由记录到的 nav age 解释”，不等于已经定位到
  可修改的 calibration 参数。
