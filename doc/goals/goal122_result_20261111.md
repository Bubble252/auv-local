## 3. 与 Goal121 的常数 bias 对照

Goal121 的常数 `stern-0.2`：

```text
success 22/40
gained 31, 56
lost 无
```

Goal122 的 PPO 方向：

```text
16x success 20/40 (+2/-2)
32x success 19/40 (+4/-5)
```

两者都有“动作权限”，但常数 `stern-` 的方向是**净增益**，PPO 放大方向是
**净交换甚至净伤害**。因此当前问题不是“PPO 完全没权限”，而是：

```text
PPO learned direction is not aligned with terminal capture
```

## 4. 解释

PPO residual 的终端均值只有 `0.007–0.016`，约为 BC base 的 3%。把它放大：

- 8x 才开始有 1 个 seed 翻转；
- 16x/32x 让终态 eta 大幅移动，但 gained/lost 同时增加；
- 64x 进入饱和/过冲，13/40。

这说明 PPO 学到的 residual 方向包含一部分有用信号，但被大量无效/反向分量
污染。它不是“小幅度正确方向”，也不是“完全惰性”。

## 5. 为什么还不开 SAC

用户条件是“残差方向对，但探索/样本效率不足”才开 SAC。Goal122 只证明：

```text
authority exists
but learned direction is not capture-aligned
```

在这个条件下直接开 SAC，可能只是换一种方式学到一个方向不对的 residual。
更便宜、更接近根因的下一步是：利用 Goal121 已经证明有效的常数 `stern-`
方向，做一次 eval-only 的常数 bias 标定，找出可复现的净增益方向和幅度；
再用它作为 PPO/SAC 的先验或动作参数化，而不是盲目换算法。

## 6. 决策

```text
decision = continue
next = Goal123 constant stern/rpm bias calibration
```

Goal123 只做 eval，不训练：

```text
stern bias: -0.05, -0.10, -0.15, -0.20, -0.25, -0.30
rpm bias:   -0.10, -0.20
combined:   stern -0.20 + rpm -0.10
```

Gate：

- 任一 bias success `>=23/40` 且 lost `<=1` → `BIAS_IMPROVES_CAPTURE`；
- 21–22/40 → `BIAS_WEAK`；
- `<=20/40` → `BIAS_NONE`；
- safety>0 或 NaN → `INVALID`。

若找到稳定 bias，再预注册“bias-initialized PPO”或“bias + RL residual”实验；
仍不换算法，不打开 held-out。
