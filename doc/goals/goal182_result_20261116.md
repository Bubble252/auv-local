### 6.2 最终状态

#### 6.2.1 首轮验证：原始 warmstart 契约无效

原始三组 600-it 使用 `runner.empirical_normalization=true`、actor LR `3e-4`、
`init_noise_std=0.3`。三组 iteration 1 的 `approx_kl` 分别为 `70.42`、`34.90`、
`51.10`，`clip_fraction≈0.98–0.99`，`ratio_max` 最高 `359`。这不是正常的 PPO
trust-region 行为。对应 run 目录保留为证据，但标为
`INVALID_WARMSTART_CONTRACT`，不再续跑或用于结论。

为拆分根因，做了四个 1-iteration 对照：

| 诊断 | normalization | actor LR | init std | iteration 1 KL | 1-seed 3D RMSE | completion | success / timeout / safety |
|---|---|---:|---:|---:|---:|---:|---:|
| `fixednorm_smoke_1it` | fixed | `3e-4` | `0.3` | `61.21` | `30.0243 m` | `0.374` | `0 / 1 / 0` |
| `empnorm_lr1e5_smoke_1it` | empirical | `1e-5` | `0.05` | `0.0087` | `9.6319 m` | `0.2495` | `0 / 0 / 1` |
| `lr1e5_smoke_1it` | fixed | `1e-5` | `0.05` | `0.0127` | `1.5316 m` | `1.000` | `0 / 0 / 0`（goal-plane miss `1.0`） |
| `fixednorm_lr1e5_screen_5it` | fixed | `1e-5` | `0.05` | `0.0127 → 0.0041` | `1.5322 m` | `1.000` | `0 / 0 / 0`（goal-plane miss `1.0`） |

结论：

- **actor LR 过大是首个 update 崩溃的直接原因**。在 fixed normalization 下，actor
  LR 从 `3e-4` 降到 `1e-5` 后，iteration 1 KL 从 `61.21` 降到 `0.0127`，3D RMSE
  从 `30.02 m` 恢复到 `1.53 m`。
- **empirical actor normalization 仍与 BC warmstart 不兼容**。即使 actor LR 已降到
  `1e-5`，empirical 版本 1-iteration 后仍是 `9.63 m`、safety `1.0`、completion
  `0.25`。rsl_rl 2.3.3 的 empirical actor/critic normalizer 会改写 BC actor 的输入
  分布，而 BC checkpoint 是在 `PCNormalization` 固定前端上训练的。
- 因而本轮完整微调采用 **fixed normalization + actor LR `1e-5` + critic LR `3e-4` +
  fixed schedule + init std `0.05`**。这与 Goal182 D3 的 A+E 全局决策存在冲突，标为
  `BC_WARMSTART_NORMALIZATION_CONFLICT_PENDING_REVIEW`；empirical 仍可用于 fresh
  policy，但不能直接用于该 BC warmstart arm。
