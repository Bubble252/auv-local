## 2. 统计判读

`stern-025` 相对 `zero`：

```text
gained = 29, 31, 33, 56
lost   = none
McNemar exact (two-sided) = 0.125
one-sided                = 0.0625
```

这不是 5% 水平显著，但它是：

- 单调剂量响应；
- 4 个 gained、0 个 lost；
- 两个相邻幅度（-0.25/-0.30）复现同一 success 集合；
- timeout/safety 全 0。

因此它是强方向性信号，不是单 seed 边界翻转。正式结论仍应写成
`dev40 directional / not yet formal`，不能写成 held-out 泛化。

## 3. 机制

`stern-` bias 是常数，不依赖反馈；它在 terminal gate 内叠加到 BC base。
Goal121 已看到 BC base 在终端窗口的 stern 通道均值是正的且很大：

```text
seed 25: 0.292
seed 27: 0.275
seed 31: 0.878
seed 50: 0.163
seed 51: 0.569
```

`stern-0.25` 相当于把 BC 的终端 stern 命令整体下调约 0.25，减少了过强的
俯仰/垂直修正。它恢复的 4 个 seed（29/31/33/56）正好是 Goal118/103 里
vertical-dominant / 近壳层失败的类型。这与“终端垂直捕获存在系统性正 stern
偏置”一致。

## 4. 与 PPO gain sweep 的对比

| 方向 | 最佳 success | gained/lost | 性质 |
|---|---:|---|---|
| PPO 8x | 21/40 | +1/0 | 幅度不够 |
| PPO 16x | 20/40 | +2/-2 | 有权限但交换 |
| PPO 32x | 19/40 | +4/-5 | 有权限但净伤害 |
| PPO 64x | 13/40 | +5/-12 | 饱和/过冲 |
| **constant stern-0.25** | **24/40** | **+4/0** | 净增益 |

所以当前问题不是“RL 没有动作权限”，也不是“PPO 幅度太小”，而是：

```text
BC base has a systematic terminal stern bias
PPO's learned residual direction is not aligned with correcting it
a simple constant bias is a better terminal parameterization
```

## 6. 决策

```text
decision = continue
next = Goal124 default-scenario guardrail + bias-initialized PPO design
```

在训练前必须先确认 `stern-025` 不伤害 default 场景（2.0 m）。Goal124 将：

1. 用同一 C3 reward、同一 checkpoint，只把 goal radius 改回 2.0；
2. 评估 `zero / stern-025 / stern-030` 三臂 dev40；
3. 若 default 不下降，预注册 **bias-initialized PPO**：
   - base = frozen BC + constant stern bias；
   - actor 输出层初始化为该 bias（或 residual 先验）；
   - 训练 10M，PPO 只学剩余残差；
   - 对照：zero-bias PPO（Goal120 P0）。
4. 不换算法，不打开 held-out，不改 success 定义。

常数 bias 本身不是最终神经策略；它的价值是给出一个可复现的终端参数化先验，
让 PPO/SAC 不必从零学一个已经被证明有效的方向。
