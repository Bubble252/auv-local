# Goal88 结果：训练时残差尺度 1.25× 提升 strict125，但 5M path 门槛差 3 mm

**日期**：2026-11-10<br>
**状态**：`PARTIAL_FORMAL / SUCCESS_PASS_PATH_GUARDRAIL_FAIL / NOT_A_GATE`<br>
**上游**：Goal88 protocol、Goal87 H87-O2/O4<br>
**性质**：1M screen + 5M formal；未打开 held-out，未换算法族。

## 1. 结论

训练时直接放大 `pc.actuator_residual_scale` 是有效方向：

- `S1.25` 在 1M screen 中把 strict125 从 BC `17/40` 提到 `20/20/19`
  （3 seeds），净 `+8/0`，pooled McNemar `p=0.0078`；
- default 为 `31/31/31`，净 `+6/-3`，`p=0.508`，不显著；
- path 3D RMSE 平均 `+0.0184 m`，在 1M screen 的 `<=0.02 m` 门槛内；
- plane-miss strict125 `0.575→0.508`，timeout `0`。

但 5M formal 没有继续提升 success，path 退化到 `+0.0231 m`，刚好超过预注册
`0.02 m` 门槛：

- 5M strict125 仍为 `20/20/19`，净 `+8/0`，`p=0.0078`；
- default `31/31/31`，净 `+6/-3`，`p=0.508`；
- actor 末层范数继续缩小（`0.62→0.10`、`0.58→0.17`、`0.58→0.06`），
  说明 5M 主要在把 normalized 残差压小，而不是继续改善闭环；
- magnitude clip 约 `0.70`，没有出现 2× 的饱和崩坏。

因此正式判读是：

```text
success_gate = PASS
path_guardrail = FAIL (0.0231 > 0.02 m)
formal = PARTIAL
```

失败原因是 **pre-goal path-tracking tradeoff**，不是探索/样本效率，也不是
reward/terminal 契约错位；因此本 Goal 不转 SAC。

## 2. 1M Pareto screen

3 seeds（86201/86202/86203），dev40，default + strict125：

| scale | default success | strict125 success | strict gain/loss | path Δ mean | path Δ median | phys residual | clip | plane-miss |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 1.0 | 31/31/30 | 17/17/17 | 0/0 | +0.0161 | +0.0107 | 55.5 | 0.656 | 0.575 |
| 1.25 | 31/31/31 | 20/20/19 | +8/0 | +0.0182 | +0.0007 | 65.1 | 0.696 | 0.508 |
| 1.5 | 31/31/31 | 20/20/20 | +9/0 | +0.0303 | +0.0160 | 75.2 | 0.738 | 0.500 |
| 1.75 | 32/32/32 | 20/20/20 | +12/3 | +0.0388 | +0.0364 | 81.2 | 0.770 | 0.500 |
| 2.0 | 32/32/33 | 21/21/21 | +15/3 | +0.0709 | +0.0900 | 91.4 | 0.795 | 0.475 |

normalized `residual_to_base_l2_ratio_mean` 在各尺度都约 `0.063–0.077`，
没有随 scale 按比例缩回；physical residual 从 55 增到 91，说明策略确实把
更大的动作权限用出来了。H88-A（动作参数化是主因）支持；H88-B（策略会把
物理幅度自我封顶）不支持；H88-C 部分支持：1.25× 是满足 path 门禁的 Pareto
点，2× 虽未饱和但 path 代价过大。

## 3. 5M formal

| arm | default success | strict125 success | strict gain/loss | McNemar | path Δ | plane-miss | timeout |
|---|---:|---:|---:|---:|---:|---:|---:|
| BC | 30/40 | 17/40 | — | — | — | 0.575 | 0 |
| S1.25 1M | 31/31/31 | 20/20/19 | +8/0 | 0.0078 | +0.0182 | 0.508 | 0 |
| S1.25 5M | 31/31/31 | 20/20/19 | +8/0 | 0.0078 | +0.0231 | 0.508 | 0 |

5M 与 1M 的 success 完全相同；差别只在 path 退化略增和 actor 末层范数继续
缩小。因此后续不需要默认把预算加到 5M，1M 已足够做这个 arm 的 screen。

## 4. 逐 seed 细节

- default：`31/31/31`，三个 seed 都是 `+2/-1`；翻转落在 seed 33 等边界点。
- strict125：`20/20/19`，seed86201/02 各 `+3/0`，seed86203 `+2/0`；
  没有 loss。成功点仍是靠近 1.25 m 边界的 seed，但三个训练 seed 方向一致。
- path 退化主要在 pre-goal tracking，而不是新增成功 episode；新增成功
  episode 的 path RMSE 反而平均改善约 `0.2 m`，代价来自原本成功 episode
  的轻微跟踪退化。

## 5. 判读与下一步

```text
H88_A = supported
H88_B = falsified
H88_C = partially_supported (1.25 Pareto, 2.0 path cost)
decision = continue
algorithm_switched = false
heldout_opened = false
```

下一步不换 SAC，也不跳 REDQ/DroQ。更合适的修复是 **terminal-gated
actuator residual**：在距离 goal 较远时把残差置零，只在进入 terminal
窗口后平滑放开。这样可以直接消除 pre-goal path 退化，同时保留终端修正；
需要新开 Goal89，并在同一 1M/dev40/default+strict125 协议下预注册。
