## 1. 结论

对 `zero / M1.0 / C1.0 / D0.5` 共 2,000 个 episode 做 first-entry、last-2s 和
terminal 几何审计。结果支持“失败在 residual 生效前已被 approach 几何决定”：

```text
strict（radius 1.25 m）：
  first_2m path3d 的 Cliff δ = -0.85 ~ -0.92
  last2s |vertical| 的 Cliff δ = -0.71 ~ -0.81
  last2s eta closure 的 Cliff δ = +0.77 ~ +0.89

default（radius 2.0 m）：
  first_3m vertical 的 Cliff δ = +0.95 ~ +0.99
  first_3m path3d   的 Cliff δ = -0.94 ~ -0.97
  last2s eta closure 的 Cliff δ = +0.84 ~ +0.92
```

方向很重要：成功 episode 的近区 `eta` 闭包速度更高（约 1.5–1.8 m/s），失败
episode 更慢（约 0.5–0.9 m/s）。所以不是“终端速度太高擦过”，而是
**失败者在最后 2 s 闭包不足，同时垂直/路径误差更大**。

vertical miss 在 strict 占主导：zero 9/16、M1.0 72/162、C1.0 79/138、
D0.5 70/135；horizontal 次之。default 的 horizontal 也不少，但 first-3m
vertical 仍是最强预测量。

因此 H131-A（垂直几何主导）在 strict 和 default 都得到支持；H131-B（水平主导）
只得到次级支持；H131-C（终端速度）得到支持，但方向是“失败者闭包不足”，
不是“速度过高”；H131-D（几何无法解释）被证伪。

## 2. 条件捕获

进入 shell 后的 success rate（success 进入数 / 所有进入数）：

| arm | scenario | 3 m | 2 m | radius |

| zero | strict | 0.649 | 0.727 | 1.000（1.25 m） |
| M1.0 | strict | 0.581 | 0.699 | 1.000 |
| C1.0 | strict | 0.628 | 0.692 | 1.000 |
| D0.5 | strict | 0.645 | 0.714 | 1.000 |
| zero | default | 0.892 | 1.000 | 1.000（2.0 m） |
| M1.0 | default | 0.831 | 1.000 | 1.000 |
| C1.0 | default | 0.907 | 1.000 | 1.000 |
| D0.5 | default | 0.902 | 1.000 | 1.000 |

strict 下即使进入 2 m，仍只有约 70% 成功；default 下所有失败都没有进入 2 m。
这说明：

- default 的失败在 2 m 之前已经决定（进入 2 m 后 100% 成功）；
- strict 的失败有一部分发生在 2 m 内，主要是垂直/路径误差和闭包不足；
- 继续调 residual cap/gate 无法改变“2 m 前已经偏了”的事实。
