# Goal34 结果：终端垂直误差是早期全程误差的延续

日期：2026-11-09<br>
总体裁决：**GLOBAL_CARRYOVER_SUPPORTED**<br>
局部裁决：`H_GLOBAL = SUPPORTED`，`H_PHASE = FALSIFIED`，
`H_SLOPE = FALSIFIED`。

## 1. 结论

Goal34 只读 Goal31 的四组 40-seed formal traces，比较了距 goal `40/30/20 m`
时的 true-state 垂直误差、terminal window 的 sign-matched closure、换向延迟和
路径垂直斜率。

- **H-GLOBAL 得到支持**：四个 block 中，距 goal `40 m` 的绝对垂直误差中位数为
  `8.05-8.94 m`，`20 m` 时为 `5.75-6.48 m`，终端仍为 `4.63-5.34 m`；
  `40 m -> terminal` 的 Spearman 为 `0.5270-0.6215`，`20 m -> terminal` 为
  `0.6631-0.7077`。终端垂直 miss 不是终端段才出现的，而是早期已经很大的
  全程垂直误差延续。
- **H-PHASE 被证伪**：sign-matched closing fraction 中位数确实偏低
  （`0.2467-0.3892`），且高 terminal-miss 组普遍更低；但有效 reversal coverage
  只有 `0.00-0.1613`，远低于预注册 `>= 0.50`，因此不能把当前结果写成换向延迟
  机制成立。已观测的少数 latency 也不能代表全体 seeds。
- **H-SLOPE 被证伪**：路径斜率绝对值中位数为 `0.0486-0.0544`，与 terminal
  垂直 miss 的描述性相关为 `0.3533-0.3841`，高斜率组在 `20 m` 的垂直误差也
  更大；但 `40 m` 的相关只有 `0.1725-0.2059`，四个 block 都未达到预注册
  `>= 0.30`。斜率更像终端前的伴随量，而不是从 `40 m` 已建立的持续偏置。

按预注册总体表，停止 authority-magnitude 线的下一步应收窄为“更早的全程垂直
跟踪/交接诊断”，而不是延长 terminal window、扫 reward 或直接改控制器。

## 3. H-GLOBAL：早期垂直误差延续（SUPPORTED）

| scenario | mode | rho40 | rho20 | ratio20 | abs40 med (m) | abs20 med (m) | terminal med (m) | verdict |

| strict125 | candidate | 0.5707 | 0.6855 | 1.2396 | 8.0510 | 5.7453 | 4.6349 | PASS |

解释：

- 四个 block 的 `rho40` 和 `rho20` 都达到预注册门槛；
- `ratio20 > 1` 说明 `20 m` 处的误差反而大于终端误差，terminal 段在闭合误差，
  但没有把误差降到捕获半径内；
- 因此终端 miss 的主线更像“早期垂直跟踪已经偏了，终端只是继续暴露这个偏差”。

限制：这是 true-state 几何诊断，不是控制器因果证明；不能据此直接改 terminal
reference 或 pitch gain。

## 4. H-PHASE：低 sign fraction，但 reversal 证据不足（FALSIFIED）

| default | baseline | 0.2467 | -0.3069 | 0.0400 | 4.0600 | -0.1409 | FAIL |
| default | candidate | 0.3881 | -0.2674 | 0.0000 | n/a | -0.1011 | FAIL |
| strict125 | baseline | 0.2845 | -0.3794 | 0.1613 | 0.9400 | -0.2194 | FAIL |
| strict125 | candidate | 0.3892 | -0.2914 | 0.0938 | 0.5000 | -0.1124 | FAIL |

解释：

- sign-matched closing fraction 偏低，且高 terminal-miss 组更低，这两项在多数
  block 上有信号；
- 但预注册要求 `reversal_coverage >= 0.50`，实际只有 `0.00-0.1613`；
  只有少数 seeds 发生有效符号切换，latency 中位数不能外推到全体；
- 按 frozen criterion，H-PHASE 仍为 `FALSIFIED`，不能改写成“换向延迟已证明”。

这不是数据无效：它是“当前 traces 没有足够的 reversal 事件来支持该机制”的
负结果。

- 因此不能把路径斜率写成从 `40 m` 建立的持续偏置。它是终端附近值得继续观察的
