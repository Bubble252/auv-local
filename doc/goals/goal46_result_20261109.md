## 1. 结论

Goal46 在同一 checkpoint、configs、dev seeds 和 Goal42 traces 上做了只读审计：

```text
H-DYNAMIC-PERSISTENCE = SUPPORTED (4/4 blocks)
H-USBL-OUTLIER-LEAK   = INSUFFICIENT (0/4 evaluable blocks; 0 accepted leaks in 458 due samples)
H-DVL-BOTTOM-OUTAGE   = INSUFFICIENT (2/4 evaluable blocks; all observed outages are early, none in late window)
H-OU-SIGMA            = SUPPORTED (4/4 blocks)
overall               = DYNAMIC_PERSISTENT_WITH_OU_ASSOCIATION
```

支持的结论有两层：

1. Goal45 的 dynamic residual 在 late window 的五个 `0.9 s` subwindow 中持续
   toward goal，不是单个 full-window median 的 artifact；
2. sampled OU stationary scale `nav_drift_sigma` 与 discordant seeds 的 late
   dynamic projection 在四个 block 中稳定同向，median Spearman `rho=0.8214`，
   block-stratified one-sided permutation `p=0.00005`。

这不等于已经识别 OU 状态的因果贡献。`nav_drift_sigma` 是 sampler 参数，不是
realized `nav_OU(t)`；association 也可能被 seed-level 的其它 hidden factor
共同驱动。Goal46 没有记录 `nav_OU`、`nav_event`、raw USBL innovation 或 DVL
outage drift 的逐项状态。

## 4. Association audit

### 4.1 USBL accepted outlier leak

45 个 discordant records 共有 `458` 个 inferred USBL due samples；其中
`usbl_leak_count=0`、`usbl_reject_count=0`。所有 block 的 discordant 子集
`usbl_leak_rate` 都没有变化，因此 rank association 不可评估：

```text
USBL verdict = INSUFFICIENT
```

这是否证 USBL outlier leak 是主因，而不是统计上证明它与 residual 无关。当前
Goal42 flags 没有在 45 个 discordant seeds 中观察到 accepted leak，因此这个
dataset 不能估计 leak-residual association。

### 4.2 DVL bottom outage

45 个 discordant records 中只有 6 个出现 episode-level DVL bottom outage，
非零 `dvl_outage_fraction` 的范围为 `0.0161-0.0242`；late window 的
`late_dvl_outage_fraction` 在 45 个 discordant records 中全部为 0。

| scenario | mode | rho | p | evaluable |
|---|---|---:|---:|---|
| default | candidate | `0.5214` | `0.0446` | yes |
| strict125 | candidate | `0.4900` | `0.1461` | yes |

另外两个 block 的 exposure variation 不足。Overall 只有 2/4 evaluable blocks，
低于预注册的 3-block 门槛：

```text
DVL verdict = INSUFFICIENT
```

方向上两个可评估 block 为正，但 family-wise `p<=0.0167` 未通过，而且所有已记录
outage 都发生在 early episode，不能支持“late outage 直接造成 late bias”。

### 4.3 OU stationary scale

`nav_drift_sigma` 与 discordant seeds 的 `dynamic_projection_m` 在四个 block
中均为正：

| scenario | mode | n | Spearman rho | permutation p |
|---|---|---:|---:|---:|
| default | baseline | 13 | `0.7802` | `0.00110` |
| default | candidate | 12 | `0.7762` | `0.00205` |
| strict125 | baseline | 13 | `0.8626` | `0.00025` |
| strict125 | candidate | 7 | `0.9643` | `0.00155` |

```text
median rho = 0.8214
positive-rho blocks = 4/4
stratified one-sided p = 0.00005
OU verdict = SUPPORTED
```

45 个 discordant records 的 `nav_drift_sigma` 范围为
`0.1338-0.4932 m`，中位数为 `0.3842 m`。本结果支持“较大的 sampled OU
stationary scale 与较大的 late dynamic projection 同向”，但不把
`nav_drift_sigma` 当作 realized OU displacement。

## 5. 假设裁决与解释边界

```text
H-DYNAMIC-PERSISTENCE = SUPPORTED
H-USBL-OUTLIER-LEAK   = INSUFFICIENT
H-DVL-BOTTOM-OUTAGE   = INSUFFICIENT
H-OU-SIGMA            = SUPPORTED
overall               = DYNAMIC_PERSISTENT_WITH_OU_ASSOCIATION
```

最稳妥的解释是：Goal45 的 dynamic residual 在时间上持续，并且其 seed-level
幅度与 OU stationary scale 强烈同向；目前没有观察到 accepted USBL leak，
DVL outage 的记录又过少且不在 late window，因此不能把 persistent bias 归因于
这两个已记录 exposure。

仍然不能排除：

- realized `nav_OU` 的具体 sample path 通过 trajectory/controller 反馈放大；
- `nav_event` 的早期 USBL 更新或未记录的 estimator 项；
- 与 `nav_drift_sigma` 共线的其它 seed-level hidden factor；
- Goal42 trace 没有记录 raw USBL innovation 和 DVL drift 的逐项状态。

## 8. 限制

- 这是 dev seeds 上的 association audit，不是因果识别或反事实分解。
- 45 个 discordant records 来自 40 个 seeds 与四个 scenario/mode blocks；block
  之间共享 seeds、sensor seed 和 OU sampler，不是独立重复实验。
- `nav_drift_sigma` 是 episode parameter；assoc 结果没有证明 realized
  `nav_OU(t)` 的 sample path 就是 dynamic residual。
- USBL/DVL 的 `INSUFFICIENT` 不能写成 `FALSIFIED`；当前记录只是没有足够 exposure
  variation 来估计 association。
- DVL 的 6 个非零 outage 全部为 early-episode，late outage fraction 全为 0；
  这只限制当前 trace 的解释，不证明未来 late outage 不会造成 bias。
- 只有一个固定 checkpoint 和单一训练 seed；不是跨训练 seed 稳定性结论。
- held-out `100-149` 未打开；本结果不能用于选择 held-out checkpoint、seed 或阈值。
