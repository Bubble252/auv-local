## 1. 结论

Goal45 只读 Goal42 traces、Goal44 late-window 结果，并用
`SyntheticSensorSuite.reset(seeds)` 确定性恢复 per-seed `nav_bias` 参数；没有调用
`prime`/`step`，没有 policy rollout。冻结裁决为：

```text
H-FIXED-RESIDUAL-DOMINANCE = FALSIFIED  (0/4 blocks)
H-DYNAMIC-RESIDUAL         = SUPPORTED  (4/4 blocks)
overall                    = DYNAMIC_RESIDUAL_DOMINANT
```

`realistic_calibrated` 的 reset residual 是 `0.2 * nav_bias`。它对 persistent late
error 的贡献有限：fixed norm 只有约 `0.064-0.090 m`，占 late error norm 约
`18%`；fixed goal projection 只占 late projection 的 `4.7%-10.0%`。因此，
Goal44 的持久 toward-goal bias 不能归因于这个已知的 fixed calibration residual。

减去 fixed residual 后，dynamic residual 的 median projection 仍有
`0.314-0.572 m`，且在 `42/45` 个 discordant seeds 上 toward goal（4/4 blocks
超过 0.80 fraction gate）。下一项应审计 dynamic OU/USBL/outage 分量。

## 5. 假设裁决与解释边界

```text
H-FIXED-RESIDUAL-DOMINANCE = FALSIFIED
H-DYNAMIC-RESIDUAL         = SUPPORTED
overall                    = DYNAMIC_RESIDUAL_DOMINANT
```

这支持“dynamic residual 主导 persistent bias”，但不等于已经定位到 OU、USBL
innovation、outlier leak 或 DVL outage drift 中的某一个。`dynamic_residual`
是 late error 减去 known fixed residual 后的剩余向量，仍可能包含 estimator 内部
未记录的校准/协议项。

fixed residual 被削弱的是“`0.2 * nav_bias` reset calibration remainder 是主要
来源”这一解释；不是否定 `nav_bias` 参数在 sensor 中存在。

## 8. 限制

- 只有一个固定 checkpoint 和单一训练 seed；不是跨训练 seed 稳定性结论。
- fixed residual 使用 reset 时的 `-0.8 * nav_bias` event offset；后续 USBL 更新会
  在 event 上继续叠加，但不会移除该 fixed offset。
- dynamic residual 不是 realized OU/USBL 分量的直接测量，只是已知 fixed 项之后的
  剩余。
- `nav_bias` 参数由 sampler 确定性恢复；本 Goal 没有验证 sampler 之外的真实硬件参数。
