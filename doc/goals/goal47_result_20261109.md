## 1. 结论

Goal47 在同一 checkpoint、configs、dev seeds 和评估协议下完成了一次本地
CPU/float64 instrumentation replay，并读取 realized estimator state：

```text
H-OU-REALIZED   = SUPPORTED (4/4 blocks)
H-NAV-EVENT     = FALSIFIED (0/4 blocks)
H-DVL-HOLD      = FALSIFIED (0/4 blocks)
H-SIGMA-PARTIAL = PARTIAL   (2/4 blocks)
overall         = REALIZED_OU_DOMINANT
```

核心结果是 accounting identity，而不是新的因果识别：

1. `exact dynamic projection = realized OU projection + event projection`
   在每个 discordant seed 的 late window 中闭合；最大逐行重建误差为
   `1.22e-14 m`，最大 event identity 误差为 `6.66e-16 m`；
2. realized OU 在四个 block 中都主导 late dynamic projection；
3. accepted USBL innovation 和 DVL hold drift 的中位 signed share 在四个 block
   都不是正 majority，因此两个 event 子假设失败；
4. sampled `nav_drift_sigma` 的 association 在 default 两个 block 被 realized OU
   projection 基本吸收，但在 strict125 两个 block 仍有很强的残差 association。

因此 Goal46 的 `nav_drift_sigma` 同向结果可以部分归因于 realized OU sample path，
但不能在 strict125 上宣称 sigma association 已由 realized OU 完全解释。

## 7. 修正记录

本 Goal 的修正都发生在结果判定前，没有改变 checkpoint、config、seed、eval
split、held-out、late window、hypothesis 或阈值。

1. **eta shape validation**：初版 analyzer 对 trace `eta` 的 width 期望写错；
   实际 schema 为 `(rows, 6)`。修正只改分析代码的 shape validator，未改
   evaluator 或 trace。
2. **componentwise median non-additivity**：初版 attribution 用
   `median(OU) + median(event)` 对比 `median(dynamic)`，但 median 不满足可加性，
   会在部分 seed 产生约 `1e-3 m` 量级的伪 reconstruction error。修正为在
   source-aligned late window 上使用 component mean projection：

   ```text
   mean(dynamic) = mean(OU) + mean(event)
   mean(event)   = mean(USBL) + mean(DVL)
   ```

   修正后最大逐行重建误差为 `1.22e-14 m`。`dynamic_projection_median_m` 继续保留，
   用于与 Goal45 CSV 和冻结的 median dynamic 门槛比较。
3. **discordant sign validation**：初版把“discordant 必须有正 dynamic
   projection”当成 validator，但 Goal45 定义是
   `discordant = success and not goal_capture_eta`，并且只要求 `late_projection`
   为正。seed 22 baseline 的 late projection 为正、dynamic projection 为负，
   属于 Goal46 已知的 3/45 负 dynamic records。修正只把 validator 改为检查
   `late_projection` 符号，label 和 hypothesis 定义未改变。
4. **event identity audit field**：在 per-seed/per-block CSV 中显式输出
   `event_identity_error_m` 和 `event_identity_error_max_m`，便于直接复核
   `<=1e-9 m` Gate；该字段不参与裁决阈值。

修正后 full analyzer 只重跑一次，overall verdict、四个 hypothesis verdict 和所有
冻结阈值均未改变。

## 9. 限制

- 这是 dev seeds 上的 realized-state accounting decomposition，不是反事实
  causal identification。
- 45 个 discordant records 来自 40 个 seeds 和四个 scenario/mode blocks；block
  之间共享 seeds、sensor seed 和 OU sampler，不是独立重复实验。
- `nav_drift_sigma` 仍是 episode parameter；Goal47 只说明 realized OU 在当前
  traces 中主导 accounting projection。
- DVL 的 `FALSIFIED` 只描述当前 late window 的零贡献，不外推未来 outage。
- strict125 的 sigma residual association 仍强；结果不支持“realized OU 已完全
  解释所有 block 的 sigma association”。
- 单一 checkpoint、单一训练 seed；不是跨训练 seed 稳定性结论。
- held-out `100-149` 未打开，本结果不能用于 held-out checkpoint/seed/threshold
  选择。
