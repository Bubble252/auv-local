## 6. 与 Goal53 的关系

Goal53 的 late-window `executor_command_std_norm` 和 terminal duration 在
strict125 两 block 与 true miss 同向，并通过 family/global permutation。但
Goal54 证明：在 terminal phase 之前冻结的 early-window 特征，即使包含同类
command/actuator variance 信息，也没有按预注册 Gate 预测 strict125 terminal
miss。因此：

1. Goal53 的 late-window association 可能是 concurrent、reverse-causal 或共同
   原因，不能当作 pre-terminal early warning；
2. “terminal phase 之前已经出现可观测控制前兆”这一机制没有被支持；
3. 不能据此启动基于 early feature 的 PPO/residual/controller 修改。

## 7. 失败解释与边界

- 这是只读 association audit，不是因果 mediation，也不是 deployable predictor
  的最终否定；它只否定本 Goal 冻结的 13 个 early 特征、8.0 s 窗口和 Gate。
- H1/H3 的 observed effect 超过阈值但 global permutation 不显著；不能把
  “effect size 看起来够大”写成 PASS，也不能换成单 block 或换 RNG 救回。
- strict125 capture/no-capture 分组较小（`7/13`、`12/7`），AUC 和 binary group
  的不确定性高；但 H1/H2 的连续 endpoint 分析仍按预注册 Gate 失败。
- default 的 H1/H3 PASS 是 negative-control 结果，不是 strict125 证据；
  它反而提示 early actuator variance 可能是通用难度相关量。
- 单一 checkpoint、单一训练 seed、dev seeds 和固定 sensor seed；不能外推到其他
  policy、训练 seed 或环境。
- 窗口固定为 `0-8.0 s`，没有做 4/6/10 s 扫描；窗口外或不同时间尺度的 early
  prediction 仍需新预注册 Goal，不能在本结果上 post-hoc 搜索。
- 没有使用 `usbl_due` 的 geometric availability、完整 estimator internal state
  或 terminal phase 内的 closed-loop intervention；这些不在本 Goal 的冻结特征内。

的路线。不得在本 Goal 内：

- 增删特征、改 8.0 s 窗口、改 covariates、改 rho/AUC 阈值或 permutation RNG；
- 把 H1/H3 的 observed effect 写成 PASS；
- 训练、reward/gamma/seed sweep、恢复 command-residual PPO/supervised residual；
- 打开 held-out `100-149`；
- 把 default PASS 或 Goal53 late-window association 当作 pre-terminal 机制。

若未来继续，必须新开预注册 Goal，明确选择：

1. 独立的 early-warning 复现：独立 seed/checkpoint、明确 lead time 和 false-alarm
   Gate；或
2. controlled intervention：在 terminal phase 内显式改变 timing/control，检验
   true miss 是否随之改变；或
3. 记录当前缺失的 estimator/controller internal state，但必须先写 instrumentation
   contract 和触发条件。
