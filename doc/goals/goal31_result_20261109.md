# Goal31 结果：路径前视终端控制 FAIL

日期：2026-11-09<br>
总体裁决：**FAIL / H1 FALSIFIED**（停止“路径前视点纯追踪”终端参考点主线）

## 1. 结论

在保持 `20 m` 终端窗口、C1 checkpoint、B0 执行链和控制增益不变的前提下，把终端
目标从“直接指向 goal”改为“沿参考路径前视点纯追踪”，没有达到预注册 Gate：

- `terminal_eta_capture` 在 default 为 `0.000`，在 strict125 只增加 `+0.025`
  （0.075 -> 0.100）；Gate 要求至少一个 scenario 达到 `+0.05`，未满足；
- terminal horizontal-normal offset 只改善 `-0.0112 m` / `-0.0143 m`，
  远低于 `-0.05 m` 阈值，bootstrap 95% CI 都跨零；
- terminal vertical offset 反而变差 `+0.1061 m` / `+0.2679 m`，CI 不跨零；
- terminal material saturation paired median delta 为 `+0.0396` / `+0.0347`，
  超过 `+0.03` 护栏；
- `success_protocol` 在 default/strict125 都下降 `-0.025`，`plane_miss` 都上升
  `+0.025`，恰好停在预注册护栏边界，没有净收益。

控制链是有效的：40/40 seeds 的 `actual_actuator` 和 `eta` 都改变；因此这是
H1 被证伪，不是 Goal29 式的 `INVALID_CONTROL_CHAIN`。

## 2. 协议

- baseline：B0，`ALOS -> zero-command-residual -> PD/PI -> actuator`；
  终端 `20 m` 内直接指向 goal；
- candidate：同一 B0、同一窗口，只把终端目标改为路径前视点
  `p_target = path.point_at_s(progress + lookahead)`，当 `p_target` 到达终点时
  自然退化为 goal；
- checkpoint：Goal27 C1 `final.pt`，SHA256
  `0851496b15ffebbc0a19bafa5bf40c0493c0d9a3f485267b75fde5f811dde5d9`；
- dev seeds：`20–59`，default 与 strict125 各 40 个 paired episodes；
- held-out：`100–149` 未打开；
- 评估：`endpoint_stop`、`realistic_calibrated`、CPU/float64、`path_dim=8`；
- 无训练、无 reward/gamma/seed/window 搜索、无 validation 调参。

默认关闭等价性：新代码重跑 seed `41` baseline，与 Goal30 baseline trace 的
45 个 trace 数组逐位一致（default 与 strict125 都是 `0` mismatch）。

goal-plane 的垂直收敛误差。

## 7. 可证伪假设裁决

- H1（路径几何保留能降低终端偏差）：**FALSIFIED**。路径 RMSE 改善，但 terminal
  vertical offset 显著变差，horizontal offset 改善不足，capture 未达到 Gate。
- H2（失败来自执行权限或状态估计）：**后续只读诊断已裁决为 FALSIFIED**，见
  `goal31_h2h3_result_20261109.md`。估计器平面误差只占 terminal miss 约 10%；
  简单 pitch/执行滞后代理的相关性也不满足预注册条件。Goal31 不据此宣称 H2 成立。
- H3（默认关闭逐位等价）：**SUPPORTED**。seed 41 replay 的 45 个 trace 数组
  default/strict125 全部一致。

## 8. 裁决与下一步

停止继续调：

- `terminal_path_preserving_enabled` 的 lookahead 参数；
- terminal window；
- reward、gamma/lambda、seed；
- command residual / supervised residual 主线。

进入 required autoresearch：记录 blocker、至少两个可证伪 hypothesis、reading note
和 ledger decision。下一步方向应是“终点平面垂直/横向误差的显式反馈或状态估计/
执行滞后诊断”，而不是继续改路径前视点。

本 Goal 不打开 held-out，不宣称 protocol success 等于 true-state capture，也不把
path RMSE 收益写成 terminal capture 收益。
