## 1. 裁决

Goal170 的 112 个 replay 全部完成：`4 arms × 4 levels × 2 radii × 3 checkpoint seeds`
加上 `zero50` 与 PPO 专用 `zero_ppo50`。没有训练、没有改 reward/terminal/success/
radius、没有打开 held-out。

结论是 **fail**，但不是“terminal capture 失败”：

- A actuator、B command 的整条路线误差几乎没有移动；A 甚至稳定退化约 `0.004–0.008 m`。
- T2-SAC 在所有 level/radius 上都让路线误差变差，current10 约 `+0.29 m`，不能归因于终点波动。
- T2-PPO 与自己的 `zero_ppo50` 几乎逐轨一致，路线 delta 约 `0.0001 m`；不是适配器阻塞，而是策略残差没有形成有效的转向权限。
- `success`、`final distance`、`goal-plane miss` 只作为二级诊断，不能改变本裁决。

## 4. PPO 残差权限审计

为了回答“是不是有残留动作但没有闭环效果”，对 current10/default/seed86201 做了
paired trace 审计。PPO 与 `zero_ppo50` 使用同一 base controller，不能用 Goal169 的
`zero50` 代替。

- PPO checkpoint 的 `actuator_residual_scale=0.25`，动作全尺度为
  `[0.349, 0.349, 1525.0]`；
- normalized `residual_action` 平均绝对值约 `4.53e-4`；
- 换算到物理执行器后，残差平均绝对值约：rudder `1.66e-5 rad`、stern
  `5.43e-5 rad`、rpm `0.208`；
- 与 `zero_ppo50` 的实际执行器差：rudder `5.33e-5 rad`、stern `7.91e-5 rad`、
  rpm `0.151`；前 200 步更小（rudder `1.14e-5 rad`、stern `3.61e-5 rad`）；
- 因而 PPO 的路线误差 delta 只有 `1e-4 m` 量级，success/plane-miss 也没有真正的
  路线机制信号。

这不是 `TRANSFER_ADAPTER_BLOCKED`：trace 能加载，policy/zero 配对完整。更准确的
判读是 `PPO_RESIDUAL_AUTHORITY_COLLAPSE`：网络输出几乎全部落在 propeller/rpm
通道，转向通道没有足够的物理权限，无法改变路线。

另一方面，T2-SAC 的残差权限很大，但路线变差；所以“残差大”并不自动等于“路线好”。
下一步不能靠继续放大 scale 或换 seed 救这个方向。

## 5. 为什么传统 ALOS 仍然赢

本 Goal 没有发现“神经网络方法一定不如传统方法”的证据；发现的是当前 replay 的
训练分布/动作接口与新 50 m guidance、route-health 目标不匹配：

1. A/B 的残留动作主要改变终端/速度，不改变整条路线的中段跟踪；
2. T2-SAC 学会了更大的动作，但把速度/横向误差一起放大，说明它优化的不是当前
   route error；
3. T2-PPO 的残差转向权限接近零，属于 policy collapse，不是“PPO 算法在这个任务
   上理论无效”；
4. `success` 不是主指标，因此不能用某个 arm 的 success 小波动覆盖路线退化。

| 假设 | 裁决 | 证据 |

| H170-C：旧 PPO checkpoint 只能在训练契约下公平评估 | `SUPPORTED_TRACE_COMPATIBLE / SPEED_GUARD_FAIL` | trace 可加载，但 PPO base 与 policy 都出现 `>2.5 m/s` episode；必须保留独立 `zero_ppo50` 配对 |

## 7. 决策与下一步

本 Goal 的 decision 为 `pivot`。不换 PPO/SAC 算法族，不扩大 goal radius，不救
success；下一步应预注册 **route-health-centered training**，而不是继续 replay 旧
checkpoint：

1. 以 Goal169 的 50 m guidance + Goal85/ Goal86 的 `z_t`/BC 契约为 base；
2. 训练 reward 的主项改为整条路线的 cross-track/vertical/3D 误差和 progress，
   采用分段或 keypoint 归一化，避免 pooled 3D RMSE 掩盖中段；
3. residual 在全程启用，但用 schedule 研究“为什么晚开有效”，并把晚开配置的优势
   迁移到中段；
4. 同一协议比较 `PPO` 与 `SAC`，两算法都跑多课程、多环境、多路径形状/长度/速度、
   噪声/current/plant mismatch；
5. 评价主指标固定为 route RMSE/p90、五段、10% keypoints、completion、progress
   efficiency；success 只作二级诊断；
6. 速度硬上限保持 `2.5 m/s`；PPO 的任何新实验必须先修复 base speed guard。
