## 1. 结论

按预注册阈值，Goal126 判：

```text
SAC_PA_HARM
strict mean = 19.75/40
default mean = 28.25/40
strict >=26: 1/8 seed
default >=31: 1/8 seed
timeout = 3, safety = 0
```

这不是“评估 scale 又放大了 2 倍”造成的假失败。修正重复缩放后，动作
`abs_max` 已回到 `0.985–1.000`，但 success 仍显著低于 fixed-bias control。
因此当前 1M SAC checkpoint 不能扩 5M formal。

## 2. 评估侧重复 scale 的修复

Goal126 初版评估同时做了两次缩放：

```text
config.actuator_residual_scale = 2.0
evaluate_pc_sac.py --residual-scale = 2.0
```

环境内部已把 normalized residual 乘以 config scale，评估器又乘一次，导致动作
在大范围被 `max_action=1.0` 截断。旧 16 个评估已归档到：

```text
artifacts/lowlevel/goal126_sac_pa_bias_20261111/eval_pre_scale_fix/eval/
```

修复后 runner 使用 `--residual-scale 1.0`，summary 明确记录：

```text
configured_actuator_residual_scale = 2.0
eval_residual_multiplier = 1.0
nominal_effective_actuator_residual_scale = 2.0
```

旧评估 strict mean `14.375`，新评估 `19.75`；两者都不是算法结论，只有新评估有效。

## 6. 解释与下一步

Goal126 证明：

```text
网络接线和 NoisyNet 不是主因
评估侧重复 scale 是旧结果 invalid 的原因
修正后 1M SAC 仍不能超过 fixed-bias control
```

但“总物理残差大”不能直接归因于 SAC：评估动作链还包含 frozen BC residual 和
`base_residual_bias`。因此进入 Goal127，只缩放 SAC 学习残差，并拆分 frozen BC
与 learner 的动作统计。
