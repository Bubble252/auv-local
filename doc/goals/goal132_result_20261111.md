## 1. 结论

16 条正式 eval 全部完成，parity 通过。7 个 zero 底座 arm 中：

```text
Z        strict 24/40 / default 33/40
Vp002    strict 23/40 / default 33/40
Vp005    strict 23/40 / default 33/40
Vm002    strict 24/40 / default 33/40
Sp005    strict 23/40 / default 33/40
Sp010    strict 22/40 / default 33/40
VSp      strict 23/40 / default 33/40
```

裁决：

- 正号垂直修正（Vp002/Vp005）没有 gain，且各损失 1 个 strict success；
- 负号垂直修正（Vm002）达到 `GEO_SAFE_PARITY`，但 success 没有增加；
- rpm closure 修正确实提高了 last-2s eta closure，但没有提高 success，剂量越大 strict 越差；
- 组合没有超过单修正；
- 所有正增益 arm 均为 `GEO_NO_EFFECT`；`Vm002` 是唯一 `GEO_SAFE_PARITY`。

因此 H132-A（正号垂直修正有效）被证伪；H132-B（闭包修正有效）被证伪；
H132-C（组合有效）被证伪；H132-D（该 eval-only 几何修正家族到上限）得到支持。

## 2. 机制证据

### 2.1 正号垂直 bias 的物理符号相反

`signed_vertical_error_m` 为正表示导航位置位于参考路径的 +vertical 轴一侧；
本仿真中正 stern-plane 会产生负 heave。因此 `Vp` 的 actuator 符号实际上在
把误差推大，`Vm` 才是物理正确方向。近区统计也一致：

```text
Vp005 strict last2s |vertical| = 0.897 m（Z 0.887 m）
Vm002 strict last2s |vertical| = 0.883 m（Z 0.887 m）
```

但正确符号的 dose 仍然太小，40-seed success 没有移动。这是下一步唯一值得
继续验证的 eval-only 方向。

### 2.2 closure 是结果描述，不是充分因果量

rpm bias 把 near-goal closure 明显推高：

```text
Z       strict/default closure 1.257 / 1.354 m/s
Sp005   strict/default closure 1.354 / 1.442 m/s
Sp010   strict/default closure 1.447 / 1.524 m/s
```

但 strict success 从 24 降到 23/22。说明“失败者 closure 较低”是几何/控制
结果的描述；直接加速近区并不能修复 terminal capture，甚至会破坏原本处在
成功边界上的样本。

### 2.3 所有 success 损失都来自边界 seed

逐 seed 配对后，Vp002/Vp005/Sp005/VSp 唯一损失的 strict seed 都是 seed 33：

```text
Z      seed 33: GOAL, terminal eta 1.247 m
Vp002  seed 33: GOAL_PLANE_MISS, terminal eta 1.259 m
Vp005  seed 33: GOAL_PLANE_MISS, terminal eta 1.274 m
Sp005  seed 33: GOAL_PLANE_MISS, terminal eta 1.291 m
Sp010  seed 31/33: terminal eta 1.288 / 1.306 m
```

strict radius 是 1.25 m，因此这些不是大范围轨迹崩溃，而是 1–6 cm 的边界翻转。
这不改变预注册 success 判读，但说明仅看 40-seed success 会把“边界样本重排”
与“系统性修复”混在一起。

