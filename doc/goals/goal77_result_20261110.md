# Goal77 结果：离线 terminal entry gate 不可用，true 与 false 都停在 goal plane 前

**日期**：2026-11-10<br>
**状态**：`GEOMETRY_GATE_NOT_SUPPORTED`<br>
**预注册**：`doc/goals/goal77_terminal_geometry_entry_gate_20261110.md`<br>
**上游**：Goal76 `LABEL_CONFLATION_CONFIRMED_BUT_DEADBAND_FAIL`

## 1. 结论

```text
H77-A plane gate -> false 降幅高，但 tight true retention 只有 6.78% / 8.00%
H77-B anisotropic gate -> tight true retention 0% / 0%
overall -> GEOMETRY_GATE_NOT_SUPPORTED
decision -> pivot to terminal capture/termination timing, not another offline gate
```

离线 plane gate 的确能去掉大部分 false-success：

| scenario | G1 tight false 降幅 | G1 tight true 保留率 |
|---|---:|---:|
| default | 91.30% | 6.78% |
| strict125 | 100.00% | 8.00% |

但它同时去掉了几乎全部 true-success。这不是阈值问题，而是绝大多数真实成功也在
到达 goal plane 前因球面 `endpoint_stop` 终止。把 `signed_offset >= 0` 当作
事后 gate，等价于把终端协议改成“必须过 plane”，会误杀正常球面捕获。

## 5. 几何口径纠正

Goal76 曾把世界坐标的 `terminal_horizontal_offset` 写成 “lateral”。该量会
重复计入沿 goal 方向的 signed offset，不是 goal 局部横向误差。Goal77 用
goal tangent 正交基重新分解后，deadband 后剩余 tight false 的中位数为：

| scenario | n | signed (m) | lateral (m) | vertical (m) | b (m) | p_nav-eta (m) |
|---|---:|---:|---:|---:|---:|---:|
| default | 34 | -1.2187 | 0.3404 | -0.4242 | 0.1319 | 0.3252 |
| strict125 | 17 | -0.6194 | -0.0021 | 0.0225 | 0.1456 | 0.2925 |

因此真正的主导项是 **signed plane shortfall**：p_nav 仍在 goal plane 前
`0.62–1.22 m` 就停止；lateral 只有 `0.34 m`（default）和接近 `0 m`
（strict125）。上次“lateral 1.24/0.76 m”的解释不成立，已同步修正 Goal76
结果和 blocker。

## 6. NoisyNet / residual 复核

本结果继续排除 NoisyNet/residual 主导：

- 评估是 deterministic mean，`sample_noise=False`；
- forced zero-residual 在 G0 仍有 `12/69`（default）和 `10/33`
  （strict125）tight false；
- Goal76 已给出 deadband 后剩余 false 中 zero-residual 占 `5/34` 和
  `6/17`，且 `residual_l2=0`；
- G1 的 true 损失不是噪声造成的，而是 true 本身也没有过 plane。

## 7. 为什么不是换算法

本轮没有 optimization/exploration 或 sample-efficiency 证据。失败机制已经
定位到终端行为：球面终止让 true 和 false 都在 plane 前结束，所以任何仅基于
terminal snapshot 的事后 gate 都不可分。下一步应检查动作参数化、terminal
reference/reward 和 capture/termination 时序，而不是启动 SAC/REDQ/DroQ。
