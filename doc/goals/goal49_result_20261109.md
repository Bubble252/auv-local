## 1. 结论

Goal49 只使用已有 Goal47 formal traces 和 CSV，没有新增 replay、训练、controller/
config/seed 改动，也没有打开 held-out。输入和统计都有效，但**预注册的 feature
coverage Gate 失败**：

```text
strict125 baseline:  9 / 12 evaluable features
strict125 candidate: 9 / 12 evaluable features
required:            10 / 12
coverage gate:       FAIL
overall:             INSUFFICIENT_FEATURE_VARIATION
```

因此不能把 Goal49 写成“controller/executor feedback 已被干净证伪”。更准确的结论是：

- 在可评估的 9 个特征中，没有任何一个在 strict125 两个 block 同时把 partial rho
  降到 `<=0.30` 且 drop `>=0.20`；
- 可评估特征的 strict125 partial rho 仍为约 `0.78-0.96`，最大 drop 只有 `0.0911`；
- family permutation 的 observed score 为 `0.0`，10,000 次 permutation 的 global
  `p=1.0`；
- 3 个冻结特征在 strict125 的 late source window 中为常数，不能参与判定：
  `executor_residual_action_l2_mean`、`guidance_terminal_phase_fraction`、
  `guidance_route_floor_active_fraction`。

诊断性的 pre-coverage verdict 是 `CONTROLLER_FEEDBACK_INSUFFICIENT`；正式 verdict
被 coverage Gate 覆盖为 `INSUFFICIENT_FEATURE_VARIATION`。这个区别很重要：没有证据
说明 controller feedback 能解释 association，但也没有足够覆盖去排除它。

这三个常数不是代码 bug，而是 feature 选择与 trace 语义不匹配：

- C1 是 **command-residual** 策略；`residual_action` 是 action-space residual，在
  这批 traces 中恒为零。真正记录在 trace 中的 command residual 是
  `command_residual_applied` / `command_corrected_physical`，但不在 Goal49 的冻结
  特征族中。
- 所有 late source rows 都处于 `guidance_terminal_phase=1`，因此 seed-level
  fraction 恒为 1；需要 episode-level phase duration 或 phase-entry time 才有变化。
- `guidance_route_floor_active` 在 late source rows 中恒为 0；需要 episode-level
  active duration 或 early/late timing 才有变化。

## 5. Permutation 与 family 结果

```text
observed global score = 0.0
valid draws           = 9998 / 10000

tracking family p     = 1.0
executor family p     = 1.0

```

由于 observed score 为 0，permutation 没有机会拒绝“没有可解释特征”的零假设。
这不是 permutation 失败；它反映可评估特征族没有候选通过预注册的单特征 Gate。

family 诊断 verdict（在 coverage 覆盖前）：

```text
H1 tracking = FALSIFIED among evaluable features
H2 executor = FALSIFIED among 5 evaluable features; residual_action not evaluable
H3 guidance = FALSIFIED among 1 evaluable feature; 2/3 features not evaluable
```

这些 `FALSIFIED` 只针对可评估子集，不能作为完整 hypothesis 的最终裁决；正式
overall 仍是 `INSUFFICIENT_FEATURE_VARIATION`。

## 6. 解释与边界

- 这是既有 Goal47 traces 上的 read-only rank association，不是因果 mediation。
- `partial_rho` 只控制 realized OU mean 和单个 feedback 特征；不能区分 mediator、
  collider 或 proxy。
- strict125 candidate 只有 7 个 discordant seeds；任何通过都需要外部复现。
- 三个常数特征说明本轮 feature family 的 coverage 不足，而不是证明 controller
  feedback 与 association 无关。
- 不新增 replay、不训练、不改 controller/config/seed、不打开 held-out。
