## 3. 逐 seed 一致性

current10：

- H3 gained seeds `21/23/24/46/51`，lost `26`，净 `+4`；
- H4 gained `23/24/27/51`，lost 0，净 `+4`；
- 两个 arm 都不是单 seed 拉动，但 H4 更干净。

current07：

- H3 没有 gained，lost `26/33/49`，净 `-3`；
- H4 gained `36/46`，lost `49`，净 `+1`。

因此 H3 的 current10 收益是真实的，但不是“全局更好”；它是 current10+ 的候选，
不能直接覆盖 nominal/current07。

## 4. 机制判读

1. K2 失败由纵向主导（Goal149：失败纵向 `1.54–2.18 m`，`88–100%` 超过 1 m）；
   K4 修好后，current05–15 的失败转为横向/航向主导（横向 `1.06–1.58 m`）。
2. 提高 heading gain 能降低 current10 的横向失败，但会提高 rudder 饱和并改变
   current07 的失败结构；这不是单纯“gain 越大越好”。
3. H157-C 成立：K2 zero 在 nominal 只有 `26/40`，K4 zero 是 `40/40`。任何在 K2
   zero 上测得的 neural Δsuccess 都混入了“补控制器”的成分。后续神经残差必须和
   K4/H3 zero 配对，不能再把 K2 zero 当作传统方法上界。
4. current15 的 H3/H4 仍只有 `15–17/40`，横向失败 `15/40`，说明强流下传统
   controller 也接近包络；这里才是神经残差/洋流观测最可能有价值的区间。
