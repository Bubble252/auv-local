读法：

1. 收益不是“所有通道一起放大 residual”；all-channel `0.75` 反而退化。
2. `P_RUD_075` 明显优于 `P_RUD_025`，说明 rudder-only 的 scale 剂量响应存在；

3. 相对 BC，`P_RUD_075` 的 40/40 个五段统计和 64/64 个 20–90% keypoint 统计都改善。
4. vertical p90 相对 BC 约恶化 `9.4 mm`，所以纵向问题没有被解决；这是横向/整条

5. `S_ALL_075` 峰值 `3.034 m/s`、224 个 overspeed steps，速度包线不合格，不能用于
   算法优势结论。

| 指标 | 结果 |
|---|---:|
| 3D route RMSE | `-0.1631 m / -9.05%` |
| cross-track p90 | `-0.2342 m` |
| vertical p90 | `+0.00004 m`（基本持平） |

| completion | `+0.00286` |
| 五段改善 | `34/40` 个 cell-segment；8/8 个 level×radius 均达到 gate |
| 20–90% keypoints | `56/64` 个 cell-keypoint；8/8 个 level×radius 均达到 gate |

| overspeed / timeout / safety | `0 / 0 / 0` |

`zero_alos50` 与 `zero_sac50` 的基线几乎一致（3D route 约 `1.8018 m`），说明
本轮不是靠一个异常 zero baseline 得到收益。

### 4.1 success tradeoff

success 只作为二级诊断。相对 ALOS，`P_RUD_075` 在多数 cell 的 success 相同或接近，
但以下 cell 更低：

| radius | level | P_RUD_075 success | ALOS success |
|---|---|---:|---:|
| strict125 | nominal | 0.875 | 0.975 |
| strict125 | current15 | 0.775 | 0.925 |

同时其 completion 和整条路线误差更好。因此正确标签是
`ROUTE_HEALTH_TRADEOFF`，不是“全面超越传统方法”。如果恢复该 goal，应先审计
terminal capture / strict125 终点行为，不应直接换算法。

## 5. 对算法问题的回答

本轮没有证据支持“SAC 算法更好”或“NoiseNet 主导”：

- `S_RUD_075` 相对 BC 为 `+5.73%` 退化，`S_ALL_075` 为 `+5.34%` 退化且 overspeed；
- `S_RUD_025` 与 BC 几乎相同，路线响应接近 0；
- `P_RUD_075` 的收益主要来自 rudder 通道权限和 3D/cross-track 路线误差，而不是
  速度或终点 success；
- 之前 residual 大但闭环不动，最符合动作通道权限/credit assignment，而不是
  NoiseNet 主导；本轮 all-channel 与 rudder-only 的分离结果支持这一点。

因此本轮的结论是：**先把 PPO 的 rudder-only 动作参数化与路线奖励跑对，再谈
SAC/REDQ/DroQ。** 不是更换主算法族。

纵向动力学的单独归因见
`doc/goals/goal173_vertical_dynamics_analysis_20261112.md`：`P_RUD_075` 的
学习器 stern residual 约为 0；`P_ALL_075` 的大 stern residual 主要在追 pitch
error；`p_nav` 纵向噪声与真实纵向误差同量级。该分析支持“动作权限 + 间接
depth 通道 + 观测噪声”，不支持 NoiseNet 主导。
