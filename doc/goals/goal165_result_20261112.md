# Goal165 结果：速度反馈修复成功，但 gain residual 仍是闭环 no-op

**日期**：2026-11-12<br>
**状态**：`GATE165_C_FAIL_NO_TERMINAL_TRAINING / SPEED_ENVELOPE_PASS / HELDOUT_CLOSED / NO_FORMAL`<br>
**上游**：`doc/goals/goal165_controller_feedback_parameterization_20261112.md`<br>
**数据**：`artifacts/lowlevel/goal165_controller_feedback_20261112/`

## 1. 结论先行

Goal165 完成了两件事：

1. **动作反馈修复有效**：`nu_ground` 下控制器不再把角速度当线速度，闭环地速峰值从
   Goal164 的 `2.558/2.623 m/s` 降到 `1.965–2.053 m/s`，所有评估格
   `eta<=2.5 m/s`，非 terminal 和 terminal 超速率都为 0。
2. **gain residual 仍然没有闭环效果**：default/strict125 的 8 个
   radius×level 格子中，3 个 policy seed 的成功数与同一个 zero block
   **逐 seed 完全相等**，Δ 全部为 `0/120`。这不是“有一点收益但没到阈值”，
   而是当前 checkpoint 对闭环结果没有任何可测改变。

因此 Gate165-C 判 `FAIL`，但不是算法失败，也不是速度契约失败。审计给出的两个
直接原因是：

- **训练 horizon 没有覆盖 terminal**：1M transitions / 1024 envs = 每环境约
  `976` 步，而 zero 闭环 episode 最短 `1291` 步、median `1749` 步；
  3 个训练 manifest 的 `completed_episodes=0`、`success_episodes=0`。
  本轮训练从未采到一次 goal 或 goal-plane-miss terminal。
- **gain residual 的物理权威过小**：近 goal 的 residual norm 约 `1.15`，
  但 requested action 的平均绝对改变只有约
  `[0.011, 0.022, 0.168]`（rudder rad / stern rad / rpm），
  闭环位置平均只改变 `4–7 mm`，最大 `2–4 cm`。归一化动作很大，物理动作几乎不变。

## 5. 动作权威：residual 很大，但几乎不推动执行器

按 `(episode seed, step)` 对齐 policy 与 zero trace，分距离统计：

| 距离 | residual norm mean | gate mean | requested action 平均绝对差 `[rudder, stern, rpm]` | eta 位置差 mean / p90 / max |
|---|---:|---:|---|---|
| `>10 m` | 0.000 | 0.000 | `[2.8e-8, 2.4e-8, 3.5e-9]` | `~1e-11 / 0 / ~1e-7 m` |
| `2–10 m` | 0.53 | 0.47 | `[0.005, 0.009, 0.065]` | `1.0e-3 / 3.0e-3 / 3.9e-2 m` |
| `<=2 m` | 1.15 | 1.00 | `[0.011, 0.022, 0.168]` | `4.6e-3 / 9.8e-3 / 3.7e-2 m` |

policy 的 actuator saturation 约 `43–55%`，policy action saturation 约
`48–58%`。也就是说，SAC 确实在近 goal 把归一化 residual 推到了 `~1.15`，
但经过 controller-gain 参数化后，rudder/stern/rpm 的物理改变只有千分之一到
百分之几，闭环位置改变是毫米级。这个 residual 不是“方向错了”，而是
**在当前参数化下没有足够 authority**。

## 6. 机制：仍是距离 schedule，不是 signed-error 反馈

current10/default 三个 policy seed 的相关性：

| seed | heading residual vs signed lateral | pitch residual vs signed vertical | heading vs distance | pitch vs distance |
|---:|---:|---:|---:|---:|
| 86201 | -0.120 | -0.008 | +0.048 | +0.265 |
| 86202 | -0.110 | +0.045 | -0.461 | -0.347 |
| 86203 | -0.110 | +0.083 | -0.364 | -0.346 |

near-goal residual 主要由 gate/距离触发，signed lateral/vertical 相关性接近 0
且跨 seed 不稳定。即使不看 horizon 问题，这个 residual 也不是可解释的
signed-error 终端修正。

| seeds nonnegative | 3/3 PASS | 3/3 PASS | 但都是 0 delta |
| other levels guard | PASS | PASS | 没有退化，也没有收益 |
| path / vertical | PASS | PASS | 轨迹几乎相同 |
| entry | PASS | PASS | 没有改善 |

| final bins | PASS | PASS | 分布相同 |
| signed-error mechanism | FAIL | FAIL | 相关性弱且不稳定 |
| residual health | PASS | PASS | 有 residual，未崩 |
| risk / speed | PASS | PASS | `eta<=2.5`，timeout/safety 为 0 |

| **pass** | **false** | **false** | 预注册 Gate 失败 |

`near` 的 BAD 不是实质退化：policy 与 zero 的 near fraction 只差约 `1e-8`，
是当前 `>= zero - 1e-12` 的严格浮点比较造成的。由于 primary delta 已经是 0，
这不改变裁决；后续分析器应改用 paired tolerance，而不是把数值噪声写成收益。

## 8. 为什么不换算法

本轮没有触发“optimization/exploration 不足”的证据：

- policy 与 zero 的成功数逐 seed 完全相同，不是“学得慢”；
- 训练没有 terminal 样本，terminal credit 根本不存在；
- gain residual 的物理 authority 只有毫米级，换 SAC/PPO/REDQ/DroQ 不会改变
  这个参数化瓶颈；
- 速度契约已经修复并通过，不能把本轮失败归因于 2.5 m/s 包线。

因此不启动 SAC 对照、不扩 seed、不放宽 2.5、不改 reward/terminal/success/radius。
下一步应先修训练 horizon，让 1M 预算真正覆盖 terminal；如果修完后 residual
仍然没有 authority，再单独预注册动作参数化修复。
