## 4. 修正量

| scenario | error norm 中位 | along-goal 中位 | A1 correction 中位 | A2 correction 中位 |
|---|---:|---:|---:|---:|
| default | 0.4340 | 0.0655 | 0.0000 | 0.1840 |

`p_nav-eta` 误差总量约 `0.43 m`，但沿-goal 分量中位只有 `0.07–0.10 m`。
Goal75 的 A1 因此对多数样本根本不触发；A2 使用完整误差范数，修正中位约
`0.18 m`，才能继续削掉 lateral/vertical 方向造成的 false。

这也解释了 Goal77 的 proper lateral 结果：剩余 false 不是纯沿-goal 偏差，
而是完整三维误差的一部分；但不能用 `p_nav-goal` 的世界水平距离代替。

## 5. 重要限制

A2 使用真实 `eta` 计算 `p_nav-eta`，是 **oracle correction**，不能在部署时
直接使用。它只能证明“如果知道完整终端估计误差，deadband 方向是对的”。

因此不能把 A2 写成可部署策略，也不能据此直接启动 SAC/REDQ/DroQ。下一步必须
预注册 observable predictor，把 `p_nav-eta` 从策略可见的终端特征预测出来；
只有 predicted correction 在 seed-held-out 验证上仍保留 true 并降低 false，
才允许考虑闭环 arm。

## 6. NoisyNet / residual

本 Goal 没有新增噪声或 residual 证据。Goal76/77 已确认：

- deterministic eval，`sample_noise=False`；
- forced zero-residual 仍保留 false；
- 低噪声 s240/s752/s880 仍贡献大部分失败。

因此 A2 的收益来自 terminal estimator error 的几何修正，不是关闭 NoisyNet
或降低 residual。

## 7. 下一步

预注册 Goal79：observable full-vector correction predictor。固定：

- 训练/验证按 seed 分组，使用 leave-one-seed-out 或固定 train/val split；
- 只使用 terminal 可见特征，不把 `eta` 或 `p_nav-eta` 作为输入；
- 预测 `p_nav-eta` 的 goal-frame 三分量，再做同一个 fixed deadband；
- 在 default/strict125 的 held-out dev seeds 上同时检查 tight true retention
  和 tight false reduction；
- 不扫模型/阈值，不打开 `100–149`，不训练 RL 策略。

若 predictor 失败，停止 bias correction 线，回到动作参数化、terminal
reference/reward 和 capture 时序；不换 RL 算法。
