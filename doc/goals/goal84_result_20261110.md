## 1. 结论

本轮只读复用 Goal83 已冻结的 20 个 run、800 个 episode；没有训练、没有新增
rollout、没有打开 held-out，也没有启动 SAC/REDQ/DroQ。结论是：

```text
H84-A contract separation -> SUPPORTED
H84-B bounded frame gap    -> SUPPORTED
H84-C strict125 chain      -> PARTIAL / NOT CONFIRMED
overall                    -> FRAME_ACCOUNTED
```

最重要的结果是：**p_nav success 不是略高，而是显著高估真实到达**。

| 指标 | 数值 |
|---|---:|
| p_nav_tight success | `336 / 800 = 0.4200` |
| eta_tight_ever | `171 / 800 = 0.2138` |
| eta_tight_at_done | `151 / 800 = 0.1888` |
| p_nav-only（p_nav 成功但 eta 从未进入） | `185` |
| eta-only（p_nav 失败但 eta 曾进入） | `20` |
| net gap `eta - p_nav`，95% CI | `-20.62 pp [-29.13, -12.50] pp` |

因此，“神经网络打不过传统方法”不能用旧 p_nav success 直接裁决；但也不能因此
宣称网络已经更好。按 true-eta 口径，当前 residual policy 和 zero-residual 都在
`21%` 左右，terminal outcome 仍是主要瓶颈。

## 2. 冻结语义

```text
deployment primary = p_nav_tight_success
research primary   = eta_tight_ever
secondary          = eta_tight_at_done
protocol label     = terminal_eta_capture_at_done
```

其中：

```text
p_nav_tight_success
  = terminal_kind == GOAL，且终止由 p_nav 的 tight radius 触发

eta_tight_ever
  = 任一 active step 满足 ||eta[t] - goal|| <= r_tight + 1e-12

eta_tight_at_done
  = ||eta[t_done] - goal|| <= r_tight + 1e-12
```

`terminal_eta_capture` 继续使用 protocol radius，只作标签诊断，不能与 tight
success 混用。后续单因素审计都必须报告 `p_nav`、`eta` 和 gap 三者。

## 3. 评估开关

两个 evaluator 已接入：

```text
--success-frame {p_nav,eta,both}
```

- `p_nav`：selected success = `p_nav_tight_success`；
- `eta`：selected research success = `eta_tight_ever`；
- `both`：默认，同时输出两者，`success_selected` 为 `null`；
- 旧字段 `success` 仍表示 p_nav，保持向后兼容；
- 开关只影响 episode / summary 输出，不影响 reset、rollout、reward、
  termination、plane-miss guard 或 checkpoint 选择。

新增字段：

```text
success_pnav_tight
success_eta_tight_ever
success_eta_tight_at_done
success_selected
success_frame
success_frame_gap_eta_minus_pnav
```

## 6. strict125 terminal chain

| root | heading median diff | heading relative diff | 95% CI | p_nav outcome diff | eta outcome diff |
|---|---:|---:|---:|---:|---:|

strict125 的 heading tracking 明显改善，但 p_nav outcome 反而下降；eta outcome
baseline 持平、candidate 只有 `+3.13 pp`。因此 H84-C 不能判为完整支持，只能记
`PARTIAL / NOT CONFIRMED`：tracking 与 outcome 之间存在稳定的 terminal-chain 断点，
candidate 的小幅 eta 改善不足以解释或抵消 p_nav 的下降。

## 7. 对当前失望结果的解释

这轮给出了比“神经网络不如传统方法”更精确的诊断：

1. 旧 p_nav success 有大量估计器假成功；`185/800` 的 p_nav success 没有对应的
   true-eta tight capture；
2. 按 true eta 看，policy 和 zero-residual 的总体 success 都在 `21%` 左右，
   当前 residual 并没有带来稳定 outcome 增益；
3. noisenet 不是主导项：Goal83 已确认 residual mapping、scale/rate 和 replay
   全部干净；
4. strict125 的 tracking 改善是真实的，但没有转化为 terminal outcome；
5. 所以现在最该查的是 terminal approach / controller authority，而不是换 SAC、
   REDQ 或 DroQ。样本效率和探索问题目前仍没有直接证据。

- 不修改 reward、action parameterization、controller、checkpoint 或 held-out。
