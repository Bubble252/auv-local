## 3. Parity 与网络结构

```text
strict/default seed+step aligned = true
action maxdiff = 0.0
residual maxdiff = 0.0
terminal kind match = true
```

本 Goal 没有训练或改网络。Goal108 audit 的 `[z_t64, zero-DADE64, command3]`、
`131→256→128→3` actor、`mu` 零初始化、无 NoisyNet 全部保持不变。因此该边际
结果不是网络结构或 NoisyNet 回归。

与历史代码逐条对照后，当前线属于 Goal86 P-A 谱系，而不是旧的 DDPG 或
Goal108 的 `path12` 随机初始化谱系：

| 谱系 | path 参数化 | BC encoder | 残差初始化 | 是否 NoisyNet |
|---|---|---|---|---|
| Goal58/59 DDPG | 旧 DDPG actor/critic | 不适用 | `sample_noise=False` 评价 | 是，但 Goal59 已排除主导 |
| Goal86 P-A SAC | `bc_path_dim=8` + endpoint4 | 加载 BC state/path | `mu=0` | 否 |
| Goal108 B20 SAC | `bc_path_dim=12`，无 endpoint split | `bc_checkpoint=null`，随机 path | `mu=0` | 否 |
| Goal108 PPO residual | `path8 + endpoint4` | frozen BC + 零末层残差 | 增量严格为 0 | 否 |
| Goal126/132/133 当前 SAC | `bc_path_dim=8` + endpoint4 | 加载 BC state/path | `mu=0`、endpoint/current 零末层 | 否 |

当前 actor 为 `131→256→128→3`，critic 为 `134→256→128→1`，state encoder
`20→128→128→64`，path encoder `8→64→64`，endpoint encoder `4→32→64`，
current encoder `3→64→64`。Goal108 已记录 63/63 tensor parity；Goal132/133
的 strict/default action 与 residual maxdiff 均为 `0.0`。因此本轮没有网络接线
回归，也不能把结果归因于 NoisyNet。
