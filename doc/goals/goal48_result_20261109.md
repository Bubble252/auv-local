Goal48 只使用 Goal47 已有 formal traces 和 CSV，没有新增 replay、训练或


最重要的结论不是“strict125 association 是噪声”。相反：

- strict125 baseline/candidate 的 partial rho 为 `0.8336/0.8858`；
- LOO median 为 `0.8204/0.8799`，95% Bayesian-bootstrap CI 为

slope/std/quadratic、四个预注册 seed covariates、USBL/DVL event timing 或
small-n 造成。下一步 pivot 到已记录 controller/executor feedback 的只读审计。

## 4. H1：OU time shape

控制 `[realized OU mean, realized OU late slope]` 后，strict125 partial rho
没有下降：

```text
baseline:  0.8336 -> 0.8959, drop = -0.0623
candidate: 0.8858 -> 0.8892, drop = -0.0035
```

两个 block 都要求 `partial rho <=0.30` 且 drop `>=0.20`；实际 rho 更高、drop
为负。`H1=FALSIFIED`。

## 8. Bootstrap amendment

第一次 full run 在 strict125 candidate 的 i.i.d. row bootstrap 上停止：
10,000 次重采样只有 `7,469` 次非退化，低于预注册的 9,000。原因是 `n=7` 的
有放回抽样产生大量重复 rank pattern，使 rank-residual variance 为 0；当时没有
读取 H1/H2/H3/H4 的 strict125 数值。

按协议 §4.4，bootstrap 改为 Dirichlet Bayesian bootstrap：

```text
w ~ Dirichlet(1, ..., 1)
weighted residualization + weighted correlation of ranks
10,000 draws, RNG 20261109, 2.5/97.5 percentile, valid >= 9,000
```

阈值、候选协变量、hypotheses 和 overall mapping 均未改变。改用后两个 strict125
block 都是 10,000/10,000 valid。
