## 1. 结论

固定 `stern=-0.25` 先验在 8 个训练 checkpoint 上没有被 PPO 破坏，但 PPO 也没有
在它之上产生可复现增益。预注册 Gate 判：

```text
PPO_BIAS_MIXED
reason = Z15 HARM, B15/B20/BP3 CEILING
```

核心数字：

| arm | bias | train scale | optimizer | strict mean | Δ strict | default mean | Δ default |
|---|---|---:|---|---:|---:|---:|---:|
| Z15 | `(0,0,0)` | 1.5 | C3 | 20.00 | -4.00 | 33.00 | 0.00 |
| B15 | `(0,-0.25,0)` | 1.5 | C3 | 24.00 | 0.00 | 33.00 | 0.00 |
| B20 | `(0,-0.25,0)` | 2.0 | C3 | 24.00 | 0.00 | 33.00 | 0.00 |
| BP3 | `(0,-0.25,0)` | 2.0 | C3 + advantage norm + reward scale 0.1 | 23.50 | -0.50 | 33.00 | 0.00 |

同 seed fixed-bias control 精确复现：

```text
86201 strict 24/40, default 33/40
86202 strict 24/40, default 33/40
timeout = 0, safety = 0
```

因此这不是 control 失效或 seed 噪声造成的 mixed。Z15 退回到无偏置的 20/40，
说明固定 bias 本身是有效的；B15/B20 精确停在固定偏置上限；BP3 改 reward/advantage
尺度后甚至少 1 个 strict success。

因此本 Goal 的失败不能归因于“网络结构接错”或“NoisyNet 主导”。当前 PPO 是

组合，不进入 actor 网络构造器，也不会改变 checkpoint 参数表。

`model_initial.pt` 的 63/63 parity 才是结构和初始化对照的有效证据。

## 5. 解释

Goal120–Goal125 连起来形成一致证据链：

```text
PPO residual 从零初始化附近开始
-> 10M 后 deterministic residual 仍只有 base 的 0.7%–4.0%
-> 放大该方向有执行器权限，但与 capture 方向不对齐
-> 加入正确固定 bias 后，闭环恢复到 24/40
-> PPO 在 bias 之上仍无增量，KL 保持 1e-4 量级
```

这不是“残差太大”，而是 **PPO 学到的增量太小，固定偏置承担了全部有效动作**。
当前证据支持 `PPO_ON_POLICY_OPTIMIZATION_LIMITED`，但不支持把 fixed bias 写成
神经网络策略收益。

而不是继续换算法。
