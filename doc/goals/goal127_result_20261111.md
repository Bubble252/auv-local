# Goal127 结果：SAC 残差方向不可复现，降幅只能缓解损伤

**日期**：2026-11-11<br>
**状态**：`COMPLETED_EVAL_ONLY / SAC_PA_SCALE_INSUFFICIENT / HELDOUT_CLOSED`<br>
**预注册**：`doc/goals/goal127_sac_pa_scale_direction_20261111.md`<br>
**上游**：Goal126 `SAC_PA_HARM`<br>
**性质**：复用 8 个 1M checkpoint；未训练、未换算法、未改 reward/terminal/success/goal radius。

## 1. 结论

剂量曲线的最佳点是 `0.125` 倍 SAC 输出：

```text
strict 22.75/40, default 32.625/40
```

它仍低于 zero-residual fixed-bias control 的 `24/33`，因此判：

```text
SAC_PA_SCALE_INSUFFICIENT
```

更重要的是逐 seed 结构：`0.125` 下 8 个 seed 为
`24/23/20/23/21/24/24/23`，没有任何 seed 超过 control；唯一明显获益的是
`86201`，且只在更大倍率出现（0.5–1.0 时 29–30）。这不是可复现的算法增益。

## 5. frozen BC 与 SAC learner 的拆分

Goal126 的旧残差指标包含 frozen BC residual、SAC learner 和 base bias，不能直接
当作“SAC 残差”。Goal127 新增拆分后：

| multiplier | learner/BC ratio ch0 | ch1 | ch2 |
|---:|---:|---:|---:|
| 0.125 | 0.059 | 0.146 | 0.371 |
| 0.25 | 0.117 | 0.180 | 0.725 |
| 0.5 | 0.240 | 0.268 | 1.506 |
| 1.0 | 0.493 | 0.479 | 2.954 |

在低倍率下 SAC learner 远小于 frozen BC residual；在高倍率下，learner 在 RPM
通道相对值最高，但三通道动作 RMS 接近。因此没有证据支持“单一执行器通道主导”。
也没有任何 NoisyNet 参数参与该结果。

## 7. 解释

当前证据链是：

```text
zero residual = 24/33
微小 SAC 残差 x0.125 = 22.75/32.62
更大残差单调伤害多数 seed
只有 86201 随倍率获益
```

所以当前 1M SAC 不是“方向对但幅度小”，也不是“方向对但幅值大”。更准确的描述是：
**单 seed 方向局部可用，跨 seed 不可复现；继续调 residual gain 不足以解决问题。**

按用户规则，此时不应换 REDQ/DroQ，也不应扩大 formal；应优先审计 reward 与
terminal capture/credit，解释为什么一个追求 episode reward 的策略会把大多数 seed
从 24 推到 14–23，同时只在 86201 上产生 30。
