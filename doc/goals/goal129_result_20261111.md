# Goal129 结果：gate/cap 能减轻 SAC 损伤，但没有任何参数化恢复到 zero

**日期**：2026-11-11<br>

**预注册**：`doc/goals/goal129_action_parameterization_gate_screen_20261111.md`<br>
**上游**：Goal128 `ACTION_PARAMETERIZATION / GEOMETRY_LIMITED`<br>
**性质**：复用 Goal126 的 8 个 1M SAC checkpoint；未训练、未换算法、未改 reward/terminal/success/goal radius。

## 1. 结论

64 条新 eval 全部完成。按预注册 Gate，四个新参数化全部是
`ACTION_PARAM_NO_EFFECT`：

```text
G1.0   strict 18.625 / default 27.625
C1.0   strict 22.750 / default 32.875
GC1.0  strict 23.125 / default 32.750
G0.125 strict 23.000 / default 32.750
zero   strict 24.000 / default 33.000
```

判读：

1. **只做近区 shell gate 太强**。G1.0 比不设 gate 的 M1.0 还差
   （18.625 vs 19.75 strict），并且把 86201 的 24→30 增益打回 28。
   这说明 learner 在 3–10 m 的 approach 修正有价值，不能一刀切关闭。
2. **BC-relative norm cap 是有效方向，但 α=0.25 仍不够**。C1.0 把 M1.0 从
   19.75/28.25 拉回 22.75/32.875，timeout 从 2/1 降到 0，但仍低于 zero；
   只有 86201 strict +1。
3. **gate+cap 最接近，但没有跨过 parity**。GC1.0 为 23.125/32.75，
   8 个 seed 中只有 86201 strict +1，其余 0 或负；不满足
   `SAFE_PARITY` 的“strict ≥24 且 default ≥33”。
4. **低幅值 gate 也不能恢复**。G0.125 为 23/32.75，说明即使把 learner 压到
   BC 的 12.6%，shell gate 仍然会损失 approach 修正，而不是单纯“幅值太大”。

因此 H129-A（近区 gate 是主因）被证伪；H129-B（幅值 cap 可恢复到 parity）
只得到部分支持；H129-C（86201 的增益依赖近区残差）被支持；H129-D
（terminal capture 是刀口，参数化只能 parity）得到支持。

最有机制依据的 falsification。

## 5. 网络结构对照（与旧代码/旧 audit 对齐）

本 Goal 所有 arms 使用同一个 checkpoint，只有推理期动作变换不同，因此
arm 间差异不可能来自网络结构。为避免把这一点当成口头假设，逐项对照
`doc/goals/goal108_network_and_noisenet_audit_20261111.md` 和当前配置：

| 项目 | Goal126/129 SAC 实际值 | 与历史的关系 |
|---|---|---|
| 特征布局 | `[z_t64, zero-DADE64, command3]`，`features_dim=131` | 与 Goal108 PPO/SAC 的融合顺序一致 |
| state encoder | `20→128→128→60`，加 4 reserved 得 `z_t64` | 与 Goal86/108 一致 |
| path encoder | `bc_path_dim=8` 的 `8→64→64` + endpoint `4→32→64`（末层零初始化） | Goal126 特意回到 Goal86 P-A 的 path8+endpoint4，不再用 Goal108 SAC 的随机 path12 |
| current encoder | `3→64→64`，末层零初始化 | 与 Goal108 audit 一致 |
| actor | `131→256→128→3`，ELU，`mu` 零初始化，`log_std=-3.0` | 与 Goal108 一致 |
| critic | `q` 输入 `131+3=134`，`256→128→1` | 与 Goal108 audit 一致 |
| NoisyNet | 无 `rho/sigma/noise` 参数 | 排除 NoisyNet 主导 |
| 评价 | deterministic，`sample_noise=False` 不适用 | 与 Goal128/129 同一评价链 |

Goal108 audit 已给出 63/63 tensor parity、actor 第一层 `256×131`、PPO/SAC
state encoder 逐元素相同、`mu` 与 `actor.4.weight` 全零等证据。Goal129
没有改这些定义；它只加了 `learner_terminal_gate_mode` 与
`learner_norm_cap_ratio` 两个推理期开关。因此网络结构问题是“已对齐但
仍失败”，不是“这次接线接错了”。

## 6. 失败归因与下一步

Goal129 把失败从“未知”缩小到：

```text
failure = channel-specific authority mismatch
          + terminal capture 的厘米级 margin
          + approach 阶段需要 learner 修正
```

不是 reward，不是 terminal credit 缺失，不是 NoisyNet，也不是网络接线。
预注册 Gate 的默认分支是转 terminal capture / approach geometry；但在
转几何之前，先用同一个 checkpoint 做一次更便宜的通道级参数化 falsification：

- rpm-only cap（只限制 propeller rpm 通道）；
- rudder/stern-only cap（对照，确认不是所有通道都该压）；
- cap 剂量 α 扫描；
- 方向一致性 gate（`cos(L, B)` 阈值），检验“方向对但幅值错”是否成立。

如果这些仍然全部 `NO_EFFECT`，才按 Gate 默认分支转 terminal capture /
approach geometry；不换 PPO/SAC 主算法，不开 REDQ/DroQ，不打开 held-out。
