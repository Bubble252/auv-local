# Goal160 结果：actuator vs command residual vs terminal-constrained command residual

**日期**：2026-11-12<br>
**状态**：`GATE_FAIL / COMMAND_RESIDUAL_HARM / ACTION_PARAMETERIZATION_NOT_BOTTLENECK / HELDOUT_CLOSED`<br>
**上游**：Goal156 `CAPTURE_TRADEOFF`、Goal159c `NO_CLOSED_LOOP_GAIN`

## 1. 执行摘要

Goal160 固定 SAC、`z_t`、H3、C3/ALOS、Goal85 位置契约、reward/terminal/
success/radius，只改变动作参数化：A actuator residual、B command residual、
C terminal-only command residual。3 seeds × 1M，dev40 × 4 levels ×
default/strict125。

结论：

- **Gate FAIL**。`current10` default 上最好的 command arm 是 C `84/120`
  （vs zero `90/120`，`-6`；vs A `91/120`，`-7`）；strict125 最好的是 B
  `49/120`（vs zero `57/120`，`-8`；vs A `53/120`，`-4`）。
- A actuator 只在 zero 附近：default `+1`、strict `-4`；没有达到 Gate。
- C terminal-only 没有优于 B，strict 反而更差（`43/120`），
  `H160-B` 不支持。
- 三臂 residual 都活跃，timeout/safety=0，finite=true；失败不是“没开残差”。
- 失败主因是 **command residual 权限过大**：post-Gate 只读 scale 诊断中，
  B/C 在 `scale=0.25` 下 current10 default 回到 `95/96`（zero `90`），
  path 3D RMSE 从 `2.062` 降到 `1.963`，final distance 从 `2.573` 降到
  `2.36`。这是诊断信号，不是本 Gate 的 PASS。

## 5. 机制证据

### 5.1 residual 活跃且 gate 生效

- A：`<=2 m` applied residual RMS 约 `127–179`（actuator 物理量），
  `>10 m` 约 `0.004–0.010`。
- B/C：`<=2 m` command residual RMS 约 `0.19–0.31`，`>10 m` 约 `0.000`。
- trace 的 `learned_residual_action` 是门控前原始输出；实际施加量在
  `residual` 字段。B/C 的 deployment command gate 实际有效。

### 5.2 entry 改善不足以换来 capture

B/C 在 current10 default 的 2 m entry 纵向 p90 有约 `-0.019 m` 的小幅改善，
但 success 反而下降 `6–7/120`。这说明 residual 在进入 2 m 后破坏了最终
capture，而不是“没有进入近区”。

### 5.3 authority scale 诊断

post-Gate、只复用 Goal160 checkpoint、不训练：

| arm | scale 1.0 | scale 0.5 | scale 0.25 | zero |
|---|---:|---:|---:|---:|
| B command | 83/120 | 95/120 | 95/120 | 90/120 |
| C terminal command | 84/120 | 93/120 | 96/120 | 90/120 |

scale 0.25 同时把 path 3D RMSE 从 zero `2.062` 降到 `1.963`，final distance
从 `2.573` 降到约 `2.36`。这把失败从“算法/样本效率”明确拉回到
“command residual authority / 动作参数化”。
