# Goal145 结果：T2 是横向 path 代价，C1 是纵向末端捕获瓶颈

**日期**：2026-11-11<br>
**预注册**：`goal145_terminal_capture_path_vertical_audit_20261111.md`<br>
**状态**：`COMPLETED_EVAL_ONLY / T2_HORIZONTAL_PATH_TRADEOFF / C1_TERMINAL_VERTICAL_DOMINANCE / C1_RESIDUAL_NO_CLOSED_LOOP_EFFECT / GOAL140_TRIGGER_DIAGNOSED / HELDOUT_CLOSED`<br>
**性质**：复用 Goal86 T2 checkpoint 和 Goal144 C1 checkpoint，补 dev40 trace；不训练、不改 reward/terminal/success/goal radius、不扫 seed、不打开 held-out。

## 1. 结论

两个问题必须分开：

1. **Goal86 T2 的 path-success 冲突不是纵向造成的。** T2-SAC 相对 zero 的 path vertical RMSE 几乎不变（`-0.0036 m`，CI 跨 0），3D path 增量主要来自 horizontal RMSE（`+0.3166 m`）；vertical MSE share 只有 `4.0%`。因此不能用 T2 的弱 success 信号支持纵向奖励臂。
2. **Goal144 C1 的失败是明确的末端纵向捕获问题。** 14 个失败 episode 的平均 final vertical miss 为 `1.572 m`，horizontal miss 只有 `0.324 m`；26 个成功 episode 分别是 `0.777 m` 和 `0.829 m`。13/14 个失败发生在 `1.25–2.0 m` 的 near-goal 外壳。
3. **但 C1 的残差闭环没有生效。** command 和 actuator 两臂在 300k 都是 policy `26/40`、zero `26/40`，success flip 为 0；400k 仍是 `0.65/0.35`。actuator residual 并非没有数值（实际执行器差异可测），但 success、plane miss 和 final geometry 没有移动。
4. **因此，下一步不能直接把 C1 归因为“奖励不够”然后盲扫 reward。** 当前 C1 reward 已经包含 `w_approach_vertical=1.0`、`w_approach_pitch=0.5`、`approach_enter_m=5`、`approach_full_m=2`。真正缺口是 terminal pitch/speed guidance 与 residual 的权限和时序。

### 2.3 裁决

```text
T2_SAC_PATH_COST = HORIZONTAL_DOMINANT

Goal140 R1/R2 不能由 T2 结果启动
```

T2-SAC 的残差确实在动作上非零（residual L2 约 `0.2–0.28`，动作接近饱和），success 翻转也真实存在；但它把横向路径推坏约 `0.3 m`，纵向几乎没动。这个现象更像 actuator residual 在 near-goal 产生了横向/转向修正，而不是纵向高度控制问题。

## 3. C1 的 terminal geometry

数据：`C1_000300000`，dev40，command/actuator 各 policy 与 zero-residual 配对；同时用 `C1_000400000` 复核。

### 3.1 success / failure 几何

| arm | group | n | final distance | final vertical | final horizontal | near-goal vertical | near-goal horizontal |
|---|---|---:|---:|---:|---:|---:|---:|
| command | success | 26 | `1.2337 m` | `0.7774 m` | `0.8290 m` | `0.8722 m` | `1.7972 m` |
| command | failure | 14 | `1.6101 m` | `1.5722 m` | `0.3235 m` | `1.7997 m` | `1.1732 m` |
| actuator | success | 26 | `1.2344 m` | `0.7775 m` | `0.8310 m` | `0.8717 m` | `1.7981 m` |
| actuator | failure | 14 | `1.6081 m` | `1.5699 m` | `0.3239 m` | `1.7984 m` | `1.1727 m` |

失败距离分布：

| final distance | count |
|---|---:|
| `1.25–1.5 m` | 7 |
| `1.5–2.0 m` | 6 |
| `>=2.0 m` | 1 |

这不是远距离跟踪失败，而是 near-goal 的纵向几何没有在捕获半径内收敛。失败组的 horizontal miss 反而更小，所以不能再用“横向路径差”解释 C1。

### 3.2 policy 与 zero 的差异

| arm | success policy/zero | plane miss policy/zero | success flips |
|---|---:|---:|---|
| command 300k | `26 / 26` | `14 / 14` | 0 |
| actuator 300k | `26 / 26` | `14 / 14` | 0 |
| command 400k | `26 / 26` | `14 / 14` | 0 |
| actuator 400k | `26 / 26` | `14 / 14` | 0 |

配对 final geometry 差值全部接近 0：

```text
command  final vertical Δ = +0.00023 m, CI [-0.00060,+0.00096]
actuator final vertical Δ = -0.00055 m, CI [-0.00149,+0.00039]
command  final horizontal Δ = -0.00193 m
actuator final horizontal Δ = -0.00049 m
```

### 3.3 残差是否真的进入执行器

- command residual 三通道 RMS：`[0.00126, 0.00032, 0.00194]`；
- actuator residual 三通道 RMS：`[0.00155, 0.00060, 0.00195]`；
- actuator 臂的 actual actuator 与 zero 有可测差异（平均逐 seed 差约 `0.167`），但 success/plane/final geometry 完全不动。

因此判读是：

```text
C1_RESIDUAL_NO_CLOSED_LOOP_EFFECT
```

这不是“残差没输出”，也不是“没有训练”，而是 residual 的幅度/方向/时序没有跨过改变末端捕获的门槛。

### 3.4 pitch / guidance 诊断

失败组与成功组的末端控制量差异：

| 指标 | success | failure |
|---|---:|---:|
| mean pitch error | `+0.0643 rad` | `-0.0535 rad` |
| guidance pitch rate clipped | `0.811` | `0.959` |
| guidance speed rate clipped | `0.120` | `0.454` |
| stern-plane |actuator| | `0.176` | `0.300` |
| stern saturation | `0` | `0` |
| pitch rate |abs| | `0.087 rad/s` | `0.171 rad/s` |

失败不是“舵面已经饱和”，而是 terminal pitch/speed guidance 的 rate clipping 和 pitch 方向偏置更严重。这个结果与 Goal113/131/133 的“pre-entry pitch lag、terminal closure 不足、geometry bias 只能移动 1 个边界样本”一致。

## 4. 与 Goal140 的关系

Goal145 触发的是 `C1_TERMINAL_VERTICAL_DOMINANCE`，不是 `T2_VERTICAL_PATH_DOMINANCE`。两者的区别：

- T2 的纵向路径没有退化，不能拿 T2 的弱 success 信号开纵向 reward；
- C1 的失败是明确的纵向末端 miss，但当前 C1 reward 已经有 `w_approach_vertical=1.0`；
- 同时 C1 residual 没有闭环效果，说明单纯加一个纵向 reward 可能只会改变 loss 尺度，不会自动解决 pitch/speed 权限。

因此 Goal140 的状态改为：

```text
TRIGGERED_BY_C1_TERMINAL_GEOMETRY
REQUIRES_NEW_PRE_REGISTERED_PILOT
NOT_AUTHORIZED_TO_SWEEP_REWARD_WEIGHTS
```

下一步必须先做一个最小、可证伪的 terminal vertical action/guidance 或 reward pilot；不能直接开 5M formal。

## 5. 决策

```text
decision = continue
next = C1 terminal vertical capture 的最小预注册 pilot：
       先做 eval-only terminal pitch/speed guidance 或 residual 权限单变量；
       然后再决定是否把 Goal140 的 potential-based vertical reward 接入训练。
```

明确不做：

- 不把 T2 的 path 退化归因于纵向；
- 不因 C1 失败直接换 SAC/PPO 或 REDQ/DroQ；
- 不扫 `w_approach_vertical` 的多个权重；
- 不打开 held-out；
- 不修改 C1 success、goal radius、terminal capture。
