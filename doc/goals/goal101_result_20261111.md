# Goal101 结果：同 checkpoint 下 BC 先验正式超过 ALOS

**日期**：2026-11-11<br>
**状态**：`BC_PRIOR_BEATS_ALOS / EVAL_ONLY / NO_TRAINING`<br>
**上游**：Goal100 `BC_SCALE_ONLY_SUPPORTED / PPO_INCREMENT_HARMFUL / NO_SAC`<br>
**性质**：冻结 Gate 的 eval-only 配对；未训练、未改 reward/terminal/success/goal
radius，未打开 held-out。

## 1. 结论

在同一个 Goal95 checkpoint、同一个 Goal85 unbiased candidate 环境、同一组
dev seeds `20–59`、同一个 `both` success frame 下：

| group | ALOS | B20 | delta | path ratio | timeout | safety |
|---|---:|---:|---:|---:|---:|---:|
| `P_D3_default` | 27/40 | **33/40** | **+6** | 1.0189 | 0/0 | 0/0 |
| `P_D3_strict125` | 14/40 | **20/40** | **+6** | 1.0172 | 0/0 | 0/0 |
| `P_BC15_default` | 27/40 | **33/40** | **+6** | 1.0189 | 0/0 | 0/0 |
| `P_BC15_strict125` | 14/40 | **20/40** | **+6** | 1.0172 | 0/0 | 0/0 |

Gate 判：

```text
BC_PRIOR_BEATS_ALOS
```

不是 `PARITY`，也不是历史谱系差异：`B20` 在两臂、两场景都高于同配置下的
真正 ALOS + PD/PI 基线；path 3D RMSE 平均只恶化 `1.81%`，低于预注册的 `5%`
上限；timeout/safety 没有增加。

这也回答了“神经网络为什么打不过传统方法”的一部分：至少当前这条
frozen-BC 路径并没有输给 ALOS。历史“神经网络打不过传统方法”的印象来自
`policy` 全开时 PPO 增量破坏 capture；Goal100/101 已把 BC 先验和 PPO 增量
拆开，不能再用 P0 policy 的结果代表 BC 网络本身。

## 2. 协议与有效性

- ALOS 定义：跳过 frozen-BC wrapper，给 `BatchedPCActuatorResidualEnv`
  发送全零 actuator residual；wrapper 的 baseline 是 ALOS + PD/PI；
- 2 arms × 2 scenarios = 4 个新 eval run；
- 每 run 40 episodes，dev seeds `20–59`；
- `success_frame=both`；
- CPU/float64，单线程 BLAS，4 进程并行；
- 所有 run 有 `summary.json` 与 `trace.npz`；
- ALOS run 的 `action_mode` 全部为 `alos`；
- ALOS 两臂逐 seed success 与 path 完全一致，符合“全零 residual 后不依赖
  policy 权重”的契约；
- smoke 中 `actuator_residual_applied` 最大值为 `0.0`，trace 无 attenuation
  或 frozen-residual 字段；
- B20 复现 Goal100 的两臂 `33/20`；
- checkpoint SHA 与 Goal95 冻结值一致；
- held-out `100–149` 未打开。

## 3. 逐 seed 变化

B20 相对 ALOS：

| group | gained | lost |
|---|---|---|
| `P_D3_default` | `24, 25, 27, 44, 49, 56, 59` | `32` |
| `P_D3_strict125` | `20, 23, 24, 34, 38, 40, 44, 45` | `29, 36` |
| `P_BC15_default` | `24, 25, 27, 44, 49, 56, 59` | `32` |
| `P_BC15_strict125` | `20, 23, 24, 34, 38, 40, 44, 45` | `29, 36` |

所以优势不是“没有代价的 seed 平移”：default 有 `+7/-1`，strict 有
`+8/-2`。但净增益稳定为 `+6`，且 lost seed 没有造成任何 timeout/safety。

## 4. 效果大小与统计风险

预注册 Gate 是计数阈值，已通过；但不能把 `+6/40` 单独写成 5% 统计显著。
对 discordant pairs 做精确 McNemar（双侧）：

| group | gained/lost | exact p（描述性） |
|---|---|---:|
| default | 7/1 | 0.070 |
| strict125 | 8/2 | 0.109 |

两臂的 ALOS 和 B20 轨迹在当前指标上相同，不能把两臂当 80 个独立样本重复
计算。因此正式结论应写成：

```text
方向一致且通过预注册计数 Gate；
逐场景 p 值未达到 0.05，formal 仍应报告 seed 集合与置信区间。
```

下一阶段不要用“显著性已证明”当作放宽 Gate 的理由。

## 5. 终端闭合

ALOS 与 B20 的 `goal_plane_miss_rate`：

| scenario | ALOS | B20 | 改善 |
|---|---:|---:|---:|
| default | 0.325 | 0.175 | 15 个百分点 |
| strict125 | 0.650 | 0.500 | 15 个百分点 |

`success_pnav_tight`、`success_eta_tight_ever`、`success_eta_tight_at_done`
在本组 four-run 中与 `both` 的 success 计数一致，说明当前主要失败仍是
goal-plane capture，而不是 p_nav/eta 口径分叉。

## 6. 判读

1. **BC 先验有真实闭环价值**：B20 不是靠历史不同谱系“赢”ALOS，而是在同
   checkpoint、同环境、同 seeds 下净增 6 个 success。
2. **PPO 增量仍然有害**：Goal100 已显示全开 PPO 从 B20 的 `33/20` 退到
   `31/32` 与 `18/18`；Goal101 进一步确认 B20 的增益不是“因为没和 ALOS
   比过”。
3. **strict 的绝对水平仍低**：B20 strict 只有 20/40，ALOS 14/40；剩余失败
   仍以 goal-plane miss 为主。
4. **不应开 SAC/REDQ/DroQ**：现在没有“方向正确但样本效率不足”的证据；
   问题是现有 PPO 增量会破坏一个已经强于 ALOS 的先验。
5. **下一步应训练有界/先验保持的 PPO**：冻结或强约束 BC 先验，只允许
   terminal-aware、norm-bounded 的增量；先 screen 证明不破坏 `33/20`，
   再考虑 formal。

## 7. 裁决

| 维度 | 结果 | 依据 |
|---|---|---|
| Gate | `BC_PRIOR_BEATS_ALOS` | 两臂 default `33>27`，strict `20>14` |
| Path | `WITHIN_5PCT` | max ratio `1.0189`，mean `1.0181` |
| Safety | `NO_INCREASE` | timeout/safety 全 0 |
| ALOS 契约 | `VALID` | 两臂逐 seed 与 path 完全一致；零 residual trace |
| 统计 | `DIRECTION_CONSISTENT_NOT_5PCT` | McNemar p 0.070/0.109 |
| 算法 | `NO_SAC` | 无样本效率 blocker；先验保持 PPO 优先 |

`decision = continue`。
