```text

rpm saturation:    0.021 -> 0.064 -> 0.083 -> 0.100 -> 0.119 -> 0.128
ground speed >=2.5: 0.000 -> 0.000 -> 0.005 -> 0.022 -> 0.052 -> 0.096
```

current07 仍在可控区：rudder 饱和 `0.352`、rpm `0.083`、ground speed p95 `2.273`，
只有 `0.5%` 时间超过 2.5 m/s；但已经有 4/40 plane miss 和 `10.9°` 平均 crab，说明
存在可学习的横向/纵向协调空间。

current10 已经进入饱和区：rudder `0.377`、rpm `0.100`、ground speed >=2.5 `2.2%`，
success 掉到 `27/40`。因此不在 current10 训练；它只作为 transfer 诊断。
