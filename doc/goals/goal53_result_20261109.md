## 6. 解释与边界

- 这是 existing 160 条 traces 上的只读 association audit，不是因果 mediation。
- 13 个特征来自 Goal50 的 late window（每个 seed `226` 行）和 episode-level
  timing；它们是 late/concurrent 特征，不是 pre-terminal predictor。
- H1/H2 的关联可能反映“终端阶段已经在偏离/挣扎”这一反向或共同原因，不能仅凭
  本结果断言 command variance 或 terminal duration 导致 miss。
- H3 null 说明这组特征在 protocol-success 子集内不足以区分 true capture；因此
  不能把 H1/H2 写成 success/capture discordance 的解释。
- 只有一个 checkpoint、一个训练 seed 和 dev seeds；candidate 的 no-capture 只有
  7 个，H3 功效有限。未打开 held-out，不能用于 checkpoint/seed/threshold 选择。
- 本结果不授权训练、reward/gamma/seed sweep、command-residual PPO/supervised
  residual 或控制器修改。
