## 2. 根因与一行修复

修复前，`src/auv_lowlevel/batch/pc_command_residual.py` 在 wrapper 构造时缓存了
当时的 path 对象：

```python
self.path = env.path
```

`BatchedPCLowLevelEnv.reset()` 会按 `path_bank[seed % 32]` 重新绑定
`env.path`，但 wrapper 自己已有 `path` 属性，`__getattr__` 不会再委托到
`env.path`。结果是：

- start state、ALOS guidance 和底层 controller 使用 reset 后正确的 seed path；
- evaluator 通过 `inner.path` 读取 goal、goal tangent、route tangent、path
  progress 和 path RMSE 时，持续读取初始化时的 path 0。

修复只删除该缓存，让 wrapper 的 `path` 继续由 `__getattr__` 动态委托给
`env.path`。没有修改 controller、guidance、reward、checkpoint、训练配置或
evaluation 阈值。

回归测试覆盖：

- `reset(seeds)` 后 wrapper path 跟随 seed-selected path；
- `reset_indices(mask, seeds)` 后 wrapper path 跟随局部 reset；
- 零命令残差 B0 stepwise 等价性保持不变。

### H-EVAL-ALIAS：SUPPORTED

Fresh trace 的四个控制字段与原始 Goal31 trace 逐位一致，只有 goal/route/path
派生量在修复后改变。根因、静态代码、回归测试和 40-seed control invariance 共同

vertical offset 变差和 terminal saturation 越界。不能把 original Goal31 的
FAIL 归因于 stale path 伪差，也不能把 strict125 的 capture 增益写成 H1 支持。
