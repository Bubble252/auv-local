## 1. 结论

```text
H79-A observable predictor Gate -> FAIL in both scenarios
H79-B no eta / p_nav-eta input    -> PASS
overall -> OBSERVABLE_FULL_VECTOR_PREDICTOR_NOT_SUPPORTED
decision -> pivot to terminal reference/reward, not alpha search
```

只用终端可见特征训练固定 ridge，再使用与 Goal78 相同的 `0.25 m` full-vector
deadband，能保留大部分 tight true，也能去掉一部分 tight false，但没有达到
预注册的 false 降幅：

| scenario | base success/true/false | pred success/true/false | true 保留率 | false 降幅 | Gate |
|---|---:|---:|---:|---:|---|
| default | 128/59/69 | 96/58/38 | 98.31% | 44.93% | FAIL (`<50%`) |
| strict125 | 58/25/33 | 45/25/20 | 100.00% | 39.39% | FAIL (`<50%`) |

这不是“predictor 完全无效”：default 多去掉 31 个 false，strict125 多去掉
13 个 false，true 只损失 1 个。但预注册 Gate 是 `>=50%`，不能事后放宽，也
不能因为方向对就改 alpha 或换模型救结果。

## 4. 预测误差

| scenario | RMSE signed/lateral/vertical (m) | R2 signed/lateral/vertical | 预测误差范数中位 | oracle 误差范数中位 | correction 中位 |
|---|---:|---:|---:|---:|---:|
| default | 0.3911 / 0.0655 / 0.0713 | -0.3792 / 0.9467 / 0.9608 | 0.3289 | 0.4340 | 0.0789 |
| strict125 | 0.3442 / 0.0625 / 0.0563 | 0.0032 / 0.9525 / 0.9710 | 0.3608 | 0.4349 | 0.1108 |

lateral/vertical 分量可以被可见特征较稳定预测，R² 约 `0.95–0.97`；signed
分量几乎不可预测，default R² 为负、strict125 接近 0。预测误差范数中位约

`0.08–0.11 m`，明显弱于 Goal78 oracle 的约 `0.18 m`。这解释了“方向对但
false 降幅不够”的现象。

## 6. NoisyNet / residual 复核

结论仍然是：**不是 NoisyNet 主导，也不是“residual 大”单独主导**。

- 正式评估是 deterministic mean，`sample_noise=False`；
- Goal76/77 已确认 forced zero-residual 仍有 `12/69`（default）和 `10/33`
  （strict125）tight false；
- Goal79 预测 correction 后，zero-residual 仍剩 `7/12`（default）和
  `8/10`（strict125）tight false；
- 低噪声的 s240/s752/s880 仍贡献大部分剩余 false，s1008 并没有单独主导。

需要区分两个量：

- policy applied residual：确定性动作偏移，剩余样本的 `residual/action` 中位
  约 `0.414`，不是 NoisyNet 采样噪声；
- NoisyNet noise/det：s240/s752/s880 只有约 `0.0049/0.0083/0.00049`，
  s1008 约 `1.056`。

如果失败由 NoisyNet 主导，应该集中在 s1008，并且关闭噪声或 zero-residual
后明显消失；实际两者都不成立。

## 7. 为什么不在本轮继续扫 predictor

预注册失败裁决写的是：

| 观察 | 判读 | 下一步 |
|---|---|---|
| 方向对但未过 Gate | 预测误差或 correction 过强/过弱 | 回 terminal reference/reward，不扫 alpha |
| 预测器接近零/无效 | 现有 terminal 特征不可预测 bias | 停止 bias correction 线 |

本轮属于第一类：true retention 仍高，false 降幅明显大于零，但 signed 分量
预测差、correction 中位偏弱。按照预注册，不再扫 ridge alpha、模型族、特征
组合或 deadband；这些都会把 Goal79 变成事后调参。

## 8. 下一步

`decision = pivot`

停止 observable bias predictor 线，转入 terminal reference/termination：

1. 预注册单因素 terminal reference 沿 goal tangent 前移；
2. 或训练期 plane-crossing reward/termination shaping；
3. 评估协议、reward 其余项、gamma、seed、checkpoint 选择规则和 held-out
   保持不变；
4. 正式训练前先做 `num_envs 128/256/512` 与 batch `256/512` 的单卡吞吐
   基准，再按 seed 分 8 张 GPU；
5. 扩大采样/批量必须另开预注册 arm，不能用来救 Goal79；
6. SAC/REDQ/DroQ 继续关闭。本轮没有 optimization/exploration 或
   sample-efficiency 证据。
