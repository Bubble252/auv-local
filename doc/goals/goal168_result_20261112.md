# Goal168 结果：terminal horizontal capture authority 审计

**日期**：2026-11-12<br>
**状态**：`AUDIT_COMPLETE / TERMINAL_HEADING_LAG_DOMINANT / NO_TRAINING / NO_CONTRACT_CHANGE / HELDOUT_CLOSED`<br>
**上游**：Goal167 `GATE167_B_FAIL_TERMINAL_HORIZONTAL_CAPTURE`

## 1. 裁决

Goal168 只读审计完成。A/B 两臂的 18 个 primary 失败全部为
`GOAL_PLANE_MISS`，机制分类高度一致：

| 分类 | A actuator | B command | 含义 |
|---|---:|---:|---|
| `TERMINAL_HEADING_LAG` | 15/18 | 15/18 | terminal phase 已生效，但命令转向所需时间超过剩余时间 |
| `PROJECTION_JUMP` | 3/18 | 3/18 | seed 26 在 `d≈10 m` 处 `path_progress` 单步跳 5.35 m |
| `GUIDANCE_NOT_ACTIVE` | 0 | 0 | terminal phase duty 在 20–15 m 为 0.96–1.00 |
| `AUTHORITY_INSUFFICIENT_AT_20M` | 0 | 0 | 20 m 入口 authority margin 2.17–33.76 |

结论：**不是 residual 动作幅度不够，也不是 20 m 处物理 authority 不够；
是 terminal homing 的转向时序太晚/太慢。** 当前 `20 m` 才开始从路径切线
转向 goal bearing，而载体在 rudder 饱和下只有约 `0.06–0.13 rad/s` 的实际
yaw rate；命令需要转 `0.74–1.47 rad`，转向时间达到剩余时间的
`0.87–1.88×`，因此横向误差在最后 10 m 继续增大，最终越平面失败。

## 2. 关键证据

### 2.1 terminal phase 确实生效

失败 episode 在 `goal_distance 20–15 m` 的 `guidance_terminal_phase`
duty cycle 为 `0.96–1.00`。不是“direct homing 没开”。

### 2.2 20 m 入口 authority 足够

`entry20 authority margin`（available yaw rate / required yaw rate）为
`2.17–33.76`。即使最大横向误差 `7.1 m` 的 seed 40，20 m 入口 margin 仍有
`2.17`。因此不是“从 20 m 开始就转不动”。

### 2.3 但转向时间超过剩余时间

`entry20 command-to-goal error` 为 `0.45–1.47 rad`；实测 yaw rate
`0.061–0.087 rad/s`（seed 26 例外，`0.132 rad/s`）。
`rotate_time_ratio = (cmd_error / omega_available) / time_to_plane`
在 15 个失败上为 `0.87–1.88`，即需要把整个剩余飞行时间都用于转向，
期间无法同时消除横向误差。

典型：

|---:|---:|---:|---:|---:|---:|---:|---|
| 26 | 3.6 | 1.2 | 33.72 | 0.45 | 0.132 | 0.23 | PROJECTION_JUMP |
| 39 | 5.7 | 4.0 | 4.54 | 1.19 | 0.061 | 1.29 | TERMINAL_HEADING_LAG |
| 40 | 11.2 | 7.1 | 2.17 | 1.47 | 0.074 | 1.88 | TERMINAL_HEADING_LAG |

| 57 | 9.5 | 1.8 | 9.26 | 0.74 | 0.061 | 0.87 | TERMINAL_HEADING_LAG |

### 2.4 横向/纵向分离

失败 episode 的横向 p90 为 `5.75–10.99 m`，纵向 p90 仅 `0.02–0.31 m`。
纵向奖励、NoiseNet、样本效率都不是主因。

### 2.5 projection jump 是次要问题

seed 26 在 `d≈10.05 m` 时 `path_progress` 从 `30.35 m` 跳到 `35.70 m`
（+5.35 m），同时横向误差仍为 `-8.73 m`。命令 heading 在跳变前后基本不变
（`0.61 -> 0.61 rad`），因此它更像路径段切换/投影更新，而不是控制命令
不连续。该 episode 仍被归为 `PROJECTION_JUMP`，但 15/18 的主因是
terminal heading lag。

## 4. 对下一步的含义

不换算法、不训练新 residual、不改 success/radius/reward/terminal。下一步应
预注册 Goal169：**deterministic terminal homing timing / blending 对照**。

最小变量：

1. 把 terminal homing 的切换距离从 `20 m` 提前到 `30/40/50 m`（同一
   zero controller，不改 success/radius）；
2. 或者从 `40 m` 到 `20 m` 做 path heading → goal bearing 的平滑 blend，
   避免阶跃转向；
3. 用同一批 18 个失败 episode 做 deterministic replay；
4. Gate 只看：`GOAL_PLANE_MISS` 是否下降、success 是否达到 `+4/120`
   default / `+2/120` strict125、path/vertical/near bins/speed 是否守住；
5. 如果 deterministic homing 成功，再把该 guidance 作为 residual 的 base，
   重新预注册 RL 对照；如果失败，再查 path family/projection。
