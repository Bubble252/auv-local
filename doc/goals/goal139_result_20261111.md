# Goal139 结果：fixed mixed-horizon 只有单 seed 信号，PPO 信用时域仍无效应

**日期**：2026-11-11<br>
**预注册**：`doc/goals/goal139_mixed_horizon_credit_20261111.md`<br>
**状态**：`MIXED_SINGLE_SEED_ONLY / MIXED_SAFETY_STOP / PPO_NO_CREDIT_HORIZON_EFFECT / NO_FORMAL / HELDOUT_CLOSED`<br>
**结论**：SAC M50 只有 86203 在 3 个 level 上出现正信号，整体 nominal strict 比 N0 低 15；M75 没有跨 seed 信号并触发 timeout/safety 护栏。PPO 三档 gamma 的 success 几乎完全相同，仍与 zero 有明显差距。固定比例 mixed-horizon 不是当前瓶颈的解法。

## 1. 协议与有效性

| 项目 | 值 |
|---|---|
| SAC arms | `M50` full-path 50% + T15 50%，`M75` full-path 25% + T15 75% |
| SAC 预算 | `2 arms × 3 seeds × 1,000,192 transitions`，6/6 完成 |
| PPO arms | `G995 / G980 / G950`，gamma 0.995/0.98/0.95，lambda 0.95 |
| PPO 预算 | `3 arms × 3 seeds × 1M`，9/9 完成 |
| 评估矩阵 | 5 levels × strict/default × dev seeds 20–59，SAC 60 runs，PPO 90 runs |
| 评估环境 | Goal134 冻结配置；SAC evaluator 使用 `goal134` 环境配置 |
| 评估起点 | 强制 `start_progress_m=0`、`start_progress_full_fraction=0` |
| held-out | `100–149` 未打开 |
| 旧结果 | Goal134 N0/zero 只读复用，未覆盖 |

SAC 训练 manifest 全部为 `total_env_transitions_actual=1,000,192`，评估 60/60 finite。
PPO 9/9 final，90/90 评估完成。没有 NaN、flew-out 或未解释 error。

混合起点接线也做了只读证伪：使用真实训练配置重建 256 个 reset，M50 的 full-path
mask 为 `50.39%`，M75 为 `27.34%`；full-path 起点为 0 m，其余为 20 m。
因此本轮的 null 不是“fraction 没生效”。

## 4. 机制判读

- **不是残差数值异常**：M50 的 policy residual L2 为 `0.41–0.48`，N0 control 为
  `0.39–0.48`；M75 也在同一量级。path ratio 为 `0.995–1.002`，authority ratio 为
  `0.96–1.02`，没有“大幅残差导致路径崩坏”的证据。
- **不是评估起点泄漏**：SAC evaluator 的 `environment_config` 是 Goal134 冻结配置，
  `start_progress_m=0`，与训练用的 M50/M75 配置分离。
- **不是简单剂量问题**：M75 的训练完成 episode 为 `1161–1192`，高于 M50 的
  `915–997`；训练 success 也更高，但完整路径评估更差，并在 combined20 出现 6 个
  timeout。更多 near-terminal 样本没有带来可迁移收益。
- **不是单 seed 就能救的弱信号**：86203 的 M50 结果确实在 3 个 level 为正，但
  nominal strict 仍低于 N0 的绝对值来自另外两个 seed；预注册要求 2/3 seeds，
  不允许换 seed 或只报 86203。
- **PPO 的 1% 残差是独立问题**：降低 gamma/GAE 没让 residual 离开 1% 量级，
  也没有改变 success。它更像优化/动作参数化问题，而不是信用时域不够短。

## 7. 决策

`pivot`，但不换算法：

- 不扩 8 seeds、不跑 5M formal；M50 未过 nominal guard，M75 有 timeout 护栏；
- 不继续扫 full-path/T15 的固定比例，也不把 86203 单 seed 结果包装成收益；
- 不启动 REDQ/DroQ 或新的 SAC 算法族；先补齐 Goal136 C-line 的阶段式课程
  （深度、路径、噪声、洋流、stage sampler 与 promotion/rollback）；
- PPO 的 1% residual 保留为独立优化/动作参数化问题，不与 C-line 合并；
- Goal140 纵向 tracking reward 继续排在 C-line 之后；Goal141 已提示的
  `GOAL > safety` 契约问题另开 terminal-contract Goal，不混入本 Gate。
