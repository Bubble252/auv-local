## 6. H3：baseline specificity 失败


default baseline 的 rho 只低于 `0.30` 阈值 `0.027049`。strict125 与 default
的差异方向和幅度都不足以通过 H3。因此即使 H1 pass，也不能声称
strict125-specific。

candidate delta 作为预注册的 support 描述为：

```text

      = 0.18277320684553316

```

这个数值名义上 `p < 0.05`，但 H2 已失败，CI 仍包含零，且 H3 的 Gate 只看
baseline delta。它不能作为 specificity 通过，也不能用于救回 H2。

## 7. H4：四个 block 仍是同一 predictor

```text
feature                  = early_tracking_heading_error_abs_mean_rad
seeds with four blocks   = 40
exact all-block equality = 40 / 40
max abs diff             = 0.0
```

baseline/candidate 与 default/strict125 的 0-6 s heading feature 逐 seed 完全
相同。它们是**同一 predictor 的不同 terminal endpoint**，不是四个独立特征
样本。H2 失败反映的是 candidate endpoint 不同，不是第二个 predictor 独立
反驳；H3 失败反映的是 strict125/default endpoint 差异不足，不是特征噪声。

这进一步限制了“heading error 是 strict125 机制量”的解释：同一个 early
heading 向量在四个 endpoint 上得到 `0.349 / 0.181 / 0.273 / -0.001`，结果
对 endpoint 敏感，且没有稳定的 mode 分离。
