# Goal100 结果：BC-only scale 2.0 达到 33/20，PPO 增量有害

**日期**：2026-11-11<br>
**状态**：`BC_SCALE_ONLY_SUPPORTED / PPO_INCREMENT_HARMFUL / NO_SAC`<br>
**上游**：Goal99 `SCHEDULE_NOT_SUPPORTED / TERMINAL_DEGRADATION_PRECEDES_2M / NO_SAC`<br>
**性质**：eval-only、冻结 Gate；未训练、未改 reward/terminal/success/goal radius，未打开 held-out。

## 1. 结论

Goal100 的冻结 Gate 通过，但通过者不是 PPO，而是 **只保留 frozen BC、关闭 PPO、
把 BC residual scale 放大到 2.00**：

```text
B20 = frozen-base + actuator_residual_scale 2.00
D3   default 33/40, strict125 20/40
BC15 default 33/40, strict125 20/40
timeout/safety = 0
path 3D RMSE 相对 B15 = 1.013x
```

对照：

| profile | PPO | scale | D3 default | BC15 default | D3 strict | BC15 strict |
|---|---|---:|---:|---:|---:|---:|
| `B15` | 关闭 | 1.50 | 31 | 31 | 20 | 20 |
| `P0_20` | checkpoint 原样 | 2.00 | 31 | 32 | 18 | 18 |
| `B20` | 关闭 | 2.00 | **33** | **33** | **20** | **20** |
| `A3` | 近场衰减 | 2.00 | 31 | 32 | 18 | 18 |
| `A2` | 近场衰减 | 2.00 | 31 | 32 | 18 | 18 |
| `A125` | 近场衰减 | 2.00 | 31 | 32 | 18 | 18 |

因此：

```text
PPO_increment_required = false
PPO_increment_harmful = true
BC_scale_2_0_primary = true
SAC_required = false
```

这不是“PPO 探索不够”或“样本效率不足”。同一 checkpoint 下，完全关闭 PPO
反而把 default 从 `P0_20` 的 31/32 提到 33/33，并让 strict 从 18/18 回到 20/20。

## 2. 协议与有效性

- dev seeds：`20–59`，每 run 40 episodes；
- scenario：Goal85 unbiased default、strict125；
- checkpoint：Goal95 `P_D3/final.pt`、`P_BC15/final.pt`；
- checkpoint SHA 与 Goal95 一致；
- success frame：`both`；
- held-out `100–149` 未打开；
- 16 个新 run 全部有 `summary.json` 和 `trace.npz`；
- `B15` / `P0_15` / `P0_20` 的参照 success 与冻结记录一致；
- attenuation trace 与 `1 - smooth_terminal_gate` 边界一致；
- timeout/safety 全部 `0`。

`B20` 的 path 3D RMSE：

| group | B15 | B20 | ratio |
|---|---:|---:|---:|
| D3 default | 2.7279 | 2.7646 | 1.0134 |
| D3 strict125 | 2.7179 | 2.7536 | 1.0131 |
| BC15 default | 2.7279 | 2.7646 | 1.0134 |
| BC15 strict125 | 2.7179 | 2.7536 | 1.0131 |

平均恶化约 `1.3%`，低于 Gate 的 `5%`。

## 3. 逐 seed 翻转

`B20` 相对 `B15`：

| group | B15 | B20 | gained | lost |
|---|---:|---:|---|---|
| D3 default | 31 | 33 | 27, 49 | — |
| BC15 default | 31 | 33 | 27, 49 | — |
| D3 strict125 | 20 | 20 | 24, 44 | 29, 33 |
| BC15 strict125 | 20 | 20 | 24, 44 | 29, 33 |

所以 `B20` 不是逐 seed 完全保留 `B15`：

- default 净增 2 个，gained 27/49，没有 lost；
- strict 净变化 0，但 success 集合发生交换：gained 24/44，lost 29/33。

这说明 scale 2.0 本身改变了终端行为，而不只是“把 PPO 去掉”。Gate 只要求
两臂 default `>=31`、strict `>=20`，`B20` 满足；但后续 formal 不能把
“strict 集合不变”写成已证明事实。

`A3/A2/A125` 相对 `B20`：

| group | A profiles | 相对 B20 gained | 相对 B20 lost |
|---|---|---|---|
| D3 default | 31 | — | 26, 59 |
| BC15 default | 32 | — | 26 |
| D3 strict | 18 | — | 22, 24 |
| BC15 strict | 18 | — | 22, 24 |

三条 attenuation 都丢掉了 strict 22/24，正是 Goal99 里被 PPO 2.00 破坏的
同一组 seed。

## 4. 为什么近场 attenuation 没恢复

三条 profile 的 attenuation 统计：

| profile | mean attenuation | zero fraction | full fraction |
|---|---:|---:|---:|
| `A3` | 0.924–0.942 | 2.9%–4.8% | 89.8%–91.5% |
| `A2` | 0.953–0.971 | 0.1%–1.8% | 92.2%–94.2% |
| `A125` | 0.975–0.990 | 0.0%–0.1% | 94.6%–96.4% |

也就是说：

- 训练配置本来就有 `10 m -> 3 m` 的 terminal gate；
- Goal100 的 attenuation 只在更靠近目标时额外乘一次；
- 大多数控制步在 `enter_m` 之外，attenuation 接近 1；
- `A3` 只有约 3%–5% 的步真正把 PPO 完全关掉；
- `A125` 几乎没有关掉 PPO。

因此 `A3/A2/A125` 实际上仍接近 `P0_20`，strict 仍 18。它们没有构成
“强到足以检验 near-field PPO 因果”的干预。真正的强干预是 `B20`：PPO 全程关闭。

这也进一步支持 Goal99 的结论：PPO 的破坏不只在最后 2 m，甚至不只在 3 m；
只在末端乘一个很窄的 attenuation 太弱。

## 5. 终端闭合与 plane-miss

- `B20` default plane-miss `0.175`，低于 `B15` 的 `0.225`；
- `B20` strict plane-miss `0.500`，与 `B15` 相同；
- `A` profiles default plane-miss `0.200–0.225`，strict `0.550`；
- strict 失败仍以 `goal_plane_miss` 为主，不是 timeout/safety。

关键 seed：

| group/seed | B15 final | B20 final | B20 outcome |
|---|---:|---:|---|
| D3 strict 22 | 1.245 | 1.244 | success |
| D3 strict 24 | 1.336 | 1.238 | success |
| D3 strict 29 | 1.243 | 1.484 | miss |
| D3 strict 33 | 1.239 | 1.365 | miss |
| D3 default 27 | 2.443 | 1.998 | success（新 gained） |
| D3 default 49 | 2.093 | 1.977 | success（新 gained） |

`B20` 的 strict 交换不是简单的“closure 全面变好”：seed 22/24 的 final distance
进入半径，seed 29/33 反而出界。下一步 formal 必须看 seed 集合，不只报总数。

## 6. 与历史 zero-residual 基线的关系

Goal85 在同一 unbiased candidate 环境、同一 dev seeds、同一 success frame 下
记录过 zero-residual（ALOS + PD/PI，学习残差置零）的历史基线：

| profile | default | strict125 | 说明 |
|---|---:|---:|---|
| Goal85 zero-residual candidate | 0.655 | 0.265 | 历史对照，不同 checkpoint 谱系 |
| Goal100 `B20` | 0.825 | 0.500 | 当前 BC-only scale 2.0 |

这不是同一个 Goal100 run 的配对结果，不能直接当成 formal 结论；但它回答了
“神经网络是否一定打不过传统”的问题：**当前这条 BC-only 神经残差在相同
unbiased candidate 配置下明显高于历史 zero-residual 基线**。真正拖后腿的是
PPO 增量，而不是神经网络本身。

为了把这句话变成可引用的正式结论，下一步应先做同 checkpoint、同配置、
同 seeds 的 ALOS/zero-residual 配对评价；不能拿不同谱系的历史数字直接报正式
提升。

## 7. 网络结构对照

Goal99 已完成并复核：

- 当前 `pc_policy.py` SHA256 与 Goal89 parity 审计完全一致：
  `2e1ebe0c0747b3abf35507c4407a1434dfaaaf8c59970484e122e409acabb1a6`；
- actor `131→256→128→3` ELU，critic `131→256→128→1` ELU；
- state encoder `20→128→128→60`，path encoder `8→64→64`，
  endpoint encoder `4→32→64`，current encoder `3→64→60`；
- `d_z_total=64`、`n_z_reserved=4`、DADE off、无 NoisyNet；
- Goal95 两个 checkpoint 的 16 个冻结浮点张量与 Goal86 `max_abs_diff=0.0`；
- 评价走确定性 `act_inference()` / `residual_action()`。

因此本 Goal 的结果不是网络接线、NoisyNet、容量或 checkpoint 错配导致的。
Goal100 只是改变了执行时的 PPO 增量开关和 residual scale，网络权重没有改。

## 8. 裁决

| 维度 | 结果 | 依据 |
|---|---|---|
| Gate | `BC_SCALE_ONLY_SUPPORTED` | `B20` 两臂 default 33、strict 20 |
| PPO | `PPO_INCREMENT_HARMFUL` | 关闭 PPO 后 default 33、strict 20 |
| Attenuation | `TOO_WEAK` | mean 0.92–0.99，zero fraction 0–4.8%，strict 仍 18 |
| 算法 | `NO_SAC` | 没有方向正确但样本效率不足的证据 |
| 下一步 | BC-only 正式配对 + prior-preserving PPO | 不再扫 attenuation 距离 |

## 9. 下一步

1. **Goal101 eval-only**：同 checkpoint、同环境、同 dev seeds，补正式的
   ALOS/zero-residual 配对基线，确认 `B20` 相对传统的真实增益。
2. 若 Goal101 通过，训练阶段只允许 **BC 先验 + 有界 PPO 修正**：
   - PPO 从零增量或很小增量开始；
   - 加 KL-to-BC / residual norm / terminal trust-region；
   - 不打开 SAC/REDQ/DroQ；
   - 任何训练 arm 必须先在 screen 上证明不破坏 `B20` 的 33/20。
3. 不再继续扫 3/2/1.25 m attenuation；数据已经说明窄带 attenuation 太弱。
4. 不打开 held-out `100–149`。
