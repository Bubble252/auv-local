# Goal136 结果：环境多样化未带来跨 seed 增益，SAC 触发安全护栏

**日期**：2026-11-11<br>
**预注册**：`doc/goals/goal136_environment_diversity_training_eval_plan_20261111.md`<br>
**状态**：`DIVERSITY_SAFETY_STOP / PPO_RESIDUAL_COLLAPSE / NO_FORMAL / HELDOUT_CLOSED`<br>
**结论**：D1/D2 的 joint-wide 环境多样化没有产生可迁移的闭环优势；SAC 在 combined20/plant20 增加 timeout 或 safety，触发 `DIVERSITY_SAFETY_STOP`。PPO 的 D1/D2 与 N0 几乎完全相同，检查发现学习残差只有 frozen-BC base 的约 0.5%–0.8%，因此本轮不能把 PPO 的 null 解释成“多样性无效”，只能判为 `PPO_RESIDUAL_COLLAPSE_NOT_DIVERSITY`。

## 3. PPO 独立裁决

PPO 与 SAC 分开训练、分开裁决，只比较同算法 N0-PPO。

| arm | nominal strict/default | current15 | current20 | plant20 | combined20 | helped seeds | max residual/base L2 |
|---|---:|---:|---:|---:|---:|---:|---:|
| N0 | 22.0/32.0 | 10.0/21.0 | 9.0/15.0 | 20.0/32.0 | 8.3/12.0 | - | 0.0066 |
| D1 | 22.0/32.0 | 10.0/21.0 | 9.7/15.0 | 20.0/32.0 | 8.7/12.0 | 0/3 | 0.0075 |
| D2 | 22.0/32.0 | 10.0/21.0 | 9.3/15.0 | 20.0/32.0 | 8.3/12.0 | 0/3 | 0.0056 |

PPO 的总结论是 `NO_DIVERSITY_EFFECT`，但机制诊断是：

```text
PPO_RESIDUAL_COLLAPSE_NOT_DIVERSITY
```

证据：

1. D1/D2 最大平均 `residual_to_base_l2_ratio_mean` 只有 `0.0075` 和 `0.0056`；
2. final actor output-layer weight norm 仅 `0.021–0.032`，且 initial 为 0；
3. 在 Goal136 协议下，frozen-BC 配对为 nominal `22/32`，与 N0/D1/D2 PPO 完全相同；
4. eval-only 放大学习残差后仍无收益：

| PPO 学习残差增益 | nominal strict default |
|---|---:|
| 1× | 22.0 / 32.0 |
| 5× | 22.0 / 32.0 |
| 20× | 21.7–22.0 / 32.0 |
| 50× | 21.3–21.7 / 31.3–32.0 |

因此当前 PPO 不是“方向对但幅度小”；把同一方向放大不产生收益，50× 反而下降。这个 null 不能归因于 D-line 多样性，也不能靠继续加 residual scale 修复。

## 4. 与传统的对比

本 Goal 需要直接回答“我们自己的方法在不同测评里有没有帮助”。本轮答案是否定的：

- SAC D1/D2 和 PPO N0/D1/D2 在所有五个 level 的 default 成功数都低于传统 zero；
- strict 只有 D1 的 current20/combined20 和 D2 的 combined20 略高于 N0 或 zero，但没有跨 seed、跨 level 迁移；
- D-line 增加的洋流、plant 和起始扰动没有把神经网络 residual 变成优势，反而放大了 SAC 的 timeout/safety。
