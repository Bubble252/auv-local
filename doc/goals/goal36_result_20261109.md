# Goal36 结果：初始垂直几何没有达到冻结的支持条件

日期：2026-11-09<br>
总体裁决：**NO_SUPPORTED_MECHANISM**<br>
局部裁决：`H_STATE = FALSIFIED`，`H_REFERENCE = FALSIFIED`，
`H_START_DYNAMICS = FALSIFIED`。

## 1. 结论

Goal36 只读 Goal31 的四组 40-seed formal traces，拆解 episode 第一行的垂直偏置。
四个预注册机制均未通过冻结判据：

- **H-STATE 失败**：世界垂直差本身很大，`72.0%-80.7%` 的 vertical-miss seeds
  超出 capture radius；但它与初始绝对垂直误差的 Spearman 只有
  `0.1008-0.1831`，与 terminal 绝对垂直误差的 Spearman 只有
  `0.4500-0.5876`，初始/终端中位数比为 `0.7048-0.7583`，均未达到
  `>=0.50 / >=0.50 / >=0.80` 的联合门槛。世界垂直差不能单独排序初始或终端
  垂直 miss。
- **H-REFERENCE 失败**：goal/route pitch 不为零，goal-tangent 投影分量中位数为
  `6.7750-6.8424 m`，占初始绝对垂直误差的 `75.7%-85.0%`，说明参考投影在
  数量级上很重要；但它与初始绝对误差的 Spearman 为 `-0.9556--0.9154`，与
  terminal 绝对误差为 `-0.5823--0.5054`，高参考组减低压组的 terminal 中位差为
  `-2.5649--2.1361 m`。方向与预注册“参考几何制造并排序初始偏置”相反，因此
  H-REFERENCE 仍为 FALSIFIED。
- **H-START-DYNAMICS 失败**：初始 pitch 和垂向速度幅度不小（中位数
  `0.1160-0.1310 rad`、`0.1384-0.1557 m/s`），但控制参考几何后的 partial
  Spearman 只有 `-0.2465--0.0749`；初始 pitch rate 中位数仅
  `0.00256-0.00264 rad/s`，低于 `0.01 rad/s`。没有任何起始动力学量通过
  `partial >=0.30` 或高低温差 `>=0.50 m` 的判据。

按预注册总体表，`NO_SUPPORTED_MECHANISM` 表示停止“初始垂直偏置排序机制”线，
不预注册控制器候选，也不因参考份额很大就改写成 SUPPORTED。

这是本次最重要的描述性发现，但不足以把 H-REFERENCE 改判为 SUPPORTED：

- 参考投影不是小量；它中位数约 `6.8 m`，并占初始绝对误差的
  `75.7%-85.0%`；
- 但它与初始和 terminal 绝对误差都是负相关，高参考组的 terminal miss 反而
  更小；
- 描述性复核显示，参考投影本身变化很窄（四个 block 的 IQR 约
  `6.74-6.98 m`），而世界垂直差变化较宽；在这个样本里，较大的参考投影常与
  相反方向的 world offset 同时出现，起抵消作用。该描述不改变预注册裁决。

因此不能写成“goal-tangent 参考几何制造了可排序的初始偏置”。如果继续研究，
必须把“近常数加性偏置”和“随 seed 变化的排序分量”分开，且需要新的预注册协议。
