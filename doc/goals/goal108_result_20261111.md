# Goal108 结果：B20 先验上的 PPO/SAC 小增量对照失败

**日期**：2026-11-11<br>
**状态**：`COMPLETED / NO_PRIOR_OPTIMIZER_GAIN / SAC_RESIDUAL_EXPLOSION / HELDOUT_CLOSED`<br>
**上游**：Goal100/101 BC 先验、Goal103/104 terminal capture、Goal107 credit/优化归因<br>
**性质**：预注册训练型 Gate；未改 reward、terminal、success、goal radius、dev seeds 或 held-out。

## 1. 结论

按 Goal108 冻结 Gate，正式判读为：

```text
NO_PRIOR_OPTIMIZER_GAIN
```

两个 arm 都没有产生先验增量收益：

- `B20-PPO` 三个 seed 全部停在 default `33/40`、strict125 `20/40`；
- `B20-SAC` 不仅没有提升，还严重破坏 B20：default `4/5/9`，strict125 `2/2/5`；
- SAC 的确定性动作接近饱和（`action_abs_max_mean ≈ 0.996`），并出现 timeout 与 safety；
- PPO 的 learned increment 很小（L2 ratio `0.0060–0.0095`），SAC 的 applied residual
  则达到 base command L2 的 `0.74–1.38`。

因此本 Goal 不能扩到 5M formal，也不换 REDQ/DroQ/DADE。下一步按预注册转
Goal109：terminal capture / reward / residual direction，而不是继续训练 PPO/SAC。

均值：

```text
default:   mean success 6.0/40, mean path RMSE 3.7707 m
strict125: mean success 3.0/40, mean path RMSE 3.7677 m
```

SAC 不是“学了但没有超过 B20”，而是**把确定性策略推到大残差并饱和**：

- 三个 seed 的 normalized action 最大绝对值都接近 `1.0`；
- 86201 的 default/strict 各有 4 个 timeout；
- 86203 的 default/strict 各有 17 个 timeout，并各有 2 个 safety；
- path RMSE 在 86202/86203 达到 B20 的约 `1.47×/1.64×`。

这和 Goal104/107 的结论一致：失败种子上更大的 residual 是伤害，不是收益。

## 4. 网络结构审计：不是 NoisyNet

实际读取 Goal86 BC、Goal108 PPO initial 和 Goal108 SAC initial 的 state_dict：

| 项目 | BC / PPO | SAC |
|---|---|---|
| `d_z_total` | 64（60 active + 4 reserved） | 64（60 active + 4 reserved） |
| state encoder | `20→128→128→60` | `20→128→128→60` |
| fused actor input | `64+64+3=131` | `64+64+3=131` |
| actor | `131→256→128→3` | `131→256→128→3` + `mu/log_std` |
| critic | `131→256→128→1` | twin `134→256→128→1` |
| NoisyNet / `rho` / sigma | 无 | 无 |
| evaluation | deterministic mean | deterministic mean |

PPO 只有一个 `std=(3,)` 的 Gaussian 参数；SAC 的随机性来自 `log_std` 和训练期
高斯策略，不是 NoisyNet。历史 NoisyNet 只属于 Goal58/59 的 DDPG 线；Goal59 的
8-seed probe 已给出 `NOISENET_DOMINANT=false`。当前 SAC 的大残差是确定性 mu
本身饱和，不是 eval 时注入噪声。

完整对照见：

```text
doc/goals/goal108_network_and_noisenet_audit_20261111.md
```

需要保留的可比性边界：Goal108 SAC 使用 `bc_path_dim=12` 的整体 path encoder，
PPO residual 使用 `path8 + endpoint4` 拆分。两者输入信息相同，但参数化不同；
这不是 `INVALID` 条件，也不能把 SAC 的退化写成纯优化器效应。由于 SAC 的退化
幅度远超 seed 噪声，并且 action 已接近饱和，这个差异不改变 Gate 结论，但应作为
后续复盘的约束。

结果后补充审计（不改冻结 Gate）：Goal86 的 P-A SAC 曾使用
`bc_path_dim=8 + endpoint4` 并加载 BC encoder；Goal108 SAC 改为
`bc_path_dim=12` 且 `bc_checkpoint=null`。逐张量检查显示 PPO/SAC 的 state
encoder 完全相同，二者输出头也都零初始化；差异集中在 path 分支。PPO 的
`path8` 末层为零，SAC 的 `path12` 末层非零。因此 SAC 的饱和不能归因于
NoisyNet，也不能写成“纯优化器不如 PPO”；它是“未对齐的 path 参数化/初始化”
下的 replay 优化发散。详细证据见
`doc/goals/goal108_network_and_noisenet_audit_20261111.md` 第 2.4 节。

补充判读：SAC 的结果比“样本效率不足”更强，它是**没有约束的 replay/熵优化把
确定性增量推到大残差**。因此不能把本 Gate 读成“SAC 只是训练不够久”，也不能
通过继续加 1M/5M 或换更多 off-policy 算法来救。
