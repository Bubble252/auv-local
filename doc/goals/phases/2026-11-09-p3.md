# P3: Goal51–Goal89

## 范围

- Goals: 39（Goal51..Goal89）
- Dates: 2026-11-09..2026-11-11
- Label: trace 契约与终端归因 / 命令残差

## 问题

- 在进入更多控制实验前，先回答三个契约问题：输入/trace 是否可信、terminal outcome 到底由什么定义、命令残差是否真的沿着“动作→执行器→状态→捕获”链路产生作用。[Goal51](../../../doc/goals/goal51_result_20261109.md)、[Goal83](../../../doc/goals/goal83_result_20261110.md)、[Goal84](../../../doc/goals/goal84_result_20261110.md)。
- 随后检验 command residual、rate limiter、终端 bias 和 BC/传统控制器残差能否在不破坏路径的前提下改善捕获。[Goal58](../../../doc/goals/goal58_result_20261109.md)、[Goal71](../../../doc/goals/goal71_result_20261110.md)、[Goal86](../../../doc/goals/goal86_t2_3seed_result_20261111.md)。

## 尝试

- 先冻结 trace/schema 和特征复现规则（Goal51–57），再做 off-policy 信用分配（Goal58）、终端门控命令残差与 12D endpoint 观测（Goal59/60）。[Goal51](../../../doc/goals/goal51_result_20261109.md)、[Goal58](../../../doc/goals/goal58_result_20261109.md)。
- 通过 terminal alignment、radius counterfactual、短 dwell、estimator/command 因果筛查、reachability/tracking 和 command rate limiter 逐层定位（Goal61–73）；再用 capture margin、bias predictor、tangent 前移参考点、plane-miss guard 和成功帧契约收口（Goal74–85）。[Goal65](../../../doc/goals/goal65_result_20261110.md)、[Goal71](../../../doc/goals/goal71_result_20261110.md)、[Goal84](../../../doc/goals/goal84_result_20261110.md)。
- 最后分离 BC 先验与传统控制器 RL 残差（Goal86），检查网络接线（Goal87），预注册 SAC 对照（Goal88），并审计 gate scope/网络结构（Goal89）。[Goal86](../../../doc/goals/goal86_t2_3seed_result_20261111.md)、[Goal89](../../../doc/goals/goal89_result_20261111.md)。

## 失败模式

- Goal55 的独立 seed-block 复现被判 `invalid`，说明特征复现本身也需要严格契约；Goal58 的 off-policy 命令残差信用分配失败，Goal76 的 success label/deadband 语义重评估失败。[Goal55](../../../doc/goals/goal55_result_20261109.md)、[Goal58](../../../doc/goals/goal58_result_20261109.md)、[Goal76](../../../doc/goals/goal76_result_20261110.md)。
- Goal86 的 T2-SAC 在三个 seed 上 success 方向为正（default 平均 `+1.67/40`，strict `+1.33/40`），但 path RMSE 平均退化 `+0.277 m`，不能进 formal。[Goal86](../../../doc/goals/goal86_t2_3seed_result_20261111.md)。
- Goal89 发现旧训练把 `r_BC` 和 `r_PPO` 一起 gate，导致 success 从 BC 的 `31/40, 20/40` 掉到 `23/40, 14/40`；这是 gate scope 错误，不是网络结构错误。[Goal89](../../../doc/goals/goal89_result_20261111.md)。

## 保留项

- 保留 trace/schema 审计、unbiased navigation/true-state eta 判分契约、动作→执行器→状态→p_nav/eta→capture 的映射，以及 `r_BC` 的执行器残差语义。[Goal84](../../../doc/goals/goal84_result_20261110.md)、[Goal85](../../../doc/goals/goal85_result_20261110.md)、[Goal83](../../../doc/goals/goal83_result_20261110.md)。
- 保留“只 gate PPO 增量”的修复方向：`ALOS + 1.25 * (r_BC + gate * r_PPO)` 应作为 Goal90 的起点，而不是把整个残差都关掉。[Goal89](../../../doc/goals/goal89_result_20261111.md)。

## 开放问题

- corrected gate 后的 PPO 增量仍然很弱，SAC 的 weak success 又伴随 path 退化；下一阶段需要固定 gate/动作契约，分别审计低噪声探索、PPO 更新调度、动作参数化和终端 credit。入口：[Goal90](../../../doc/goals/goal90_result_20261111.md)、[Goal95](../../../doc/goals/goal95_result_20261111.md)。
