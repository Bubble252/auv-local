# P2: Goal27–Goal50

## 范围

- Goals: 24（Goal27..Goal50）
- Dates: 2026-11-09
- Label: 终端捕获与纵向 miss / 估计器诊断

## 问题

- MVP/BC 基线完成后，最大的失败不再是“飞不起来”，而是终点附近横向/纵向捕获不足、过平面 miss 和估计器时序误差。P2 要把 terminal miss 拆成几何、控制权限、状态估计和路径跟踪四类来源。[Goal28](../../../doc/goals/goal28_result_20261109.md)、[Goal31](../../../doc/goals/goal31_result_20261109.md)、[Goal40](../../../doc/goals/goal40_result_20261109.md)。
- 同时检验“保留路径几何能否自动改善终点”“vertical miss 是初始偏置还是末段权限”“strict125 的 sigma residual 是否来自已记录的估计器/时序特征”。[Goal34](../../../doc/goals/goal34_result_20261109.md)、[Goal48](../../../doc/goals/goal48_result_20261109.md)。

## 尝试

- 先用 H3-SR 监督残差预注册（Goal27），再依次做任务级 terminal miss（Goal28）、横向捕获窗口（Goal29/30）、路径保持型前视点（Goal31）、垂直权限与初始偏置诊断（Goal32–36）。[Goal27](../../../doc/goals/goal27_result_20261109.md)、[Goal31](../../../doc/goals/goal31_result_20261109.md)。
- 修复命令残差 wrapper 的 provenance（Goal38），随后系统审计 terminal miss 分量、p_nav/eta 偏差、calibration/nav-age、OU/USBL/DVL-outage 和 controller/executor feedback（Goal40–50）。[Goal38](../../../doc/goals/goal38_result_20261109.md)、[Goal50](../../../doc/goals/goal50_result_20261109.md)。

## 失败模式

- Goal31 是代表性负结果：候选把 path 3D/vertical RMSE 改善了约 `0.11/0.055 m`，但 terminal vertical offset 反而增加 `+0.106 m`（default）和 `+0.268 m`（strict125），说明“路径几何变好”不等于“终点捕获变好”。[Goal31](../../../doc/goals/goal31_result_20261109.md)。
- Goal37/39 出现坐标系重投影和 provenance 问题，部分诊断被判 `invalid`；Goal48–50 的 13 个已记录特征都不能把 strict125 sigma residual 的 partial correlation 降到 Gate 要求，最终是 `RECORDED_FEATURES_INSUFFICIENT`。[Goal37](../../../doc/goals/goal37_result_20261109.md)、[Goal50](../../../doc/goals/goal50_result_20261109.md)。

## 保留项

- 保留 terminal miss 的分量拆解、p_nav/eta 方向审计、nav-age/estimator instrumentation，以及 Goal38 修复后的一致 provenance。它们让后续实验不再把“路径 RMSE”误当成“捕获成功”。[Goal38](../../../doc/goals/goal38_result_20261109.md)、[Goal47](../../../doc/goals/goal47_result_20261109.md)。
- 保留“先做只读诊断、再改控制/奖励”的纪律；Goal31 和 Goal50 都证明继续调 lookahead、reward 或 seed 不是正确下一步。[Goal31](../../../doc/goals/goal31_result_20261109.md)、[Goal50](../../../doc/goals/goal50_result_20261109.md)。

## 开放问题

- 终端横向/纵向权限、估计器噪声和动作参数化仍未被统一解释；需要先冻结输入/trace/outcome 契约，再检验命令残差和 reward 的作用。入口：[Goal51](../../../doc/goals/goal51_result_20261109.md)、[Goal58](../../../doc/goals/goal58_result_20261109.md)。
