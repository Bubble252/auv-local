# P4: Goal90–Goal106

## 范围

- Goals: 17（Goal90..Goal106）
- Dates: 2026-11-11
- Label: corrected residual gate / PPO 信用与 B20

## 问题

- Goal89 暴露 gate scope 错误后，本阶段只回答两个问题：corrected gate 能否在不退化 path 的情况下保留 PPO 增量，以及 residual 的更新调度、方向和动作参数化是否还有可测空间。[Goal90](../../../doc/goals/goal90_result_20261111.md)、[Goal92](../../../doc/goals/goal92_result_20261111.md)。
- 在 B20 strict 失败后，进一步判断失败是 terminal capture、reward/credit、网络容量还是动作通道/限幅造成的。[Goal96](../../../doc/goals/goal96_result_20261111.md)、[Goal103](../../../doc/goals/goal103_result_20261111.md)。

## 尝试

- 用 `ALOS + 1.25 * (r_BC + gate * r_PPO)` 重做 PG20_5/PG10_3 两个 gate profile，再做低噪声 PPO、更新调度、方向/权限、rate-aware residual 和监督残差预训练（Goal90–95）。[Goal90](../../../doc/goals/goal90_result_20261111.md)、[Goal92](../../../doc/goals/goal92_result_20261111.md)、[Goal95](../../../doc/goals/goal95_result_20261111.md)。
- 对 terminal credit、PPO prior 保持、residual scale 双侧网格、距离调度、ALOS/BC-only 配对和 PPO 剂量-反应做只读或小规模 screen（Goal96–102）。[Goal96](../../../doc/goals/goal96_result_20261111.md)、[Goal98](../../../doc/goals/goal98_result_20261111.md)、[Goal102](../../../doc/goals/goal102_result_20261111.md)。
- 对 B20 的 terminal capture、分通道动作参数化、RPM 降权与 near-terminal rpm gate 做 eval-only 审计（Goal103–106）。[Goal103](../../../doc/goals/goal103_result_20261111.md)、[Goal104](../../../doc/goals/goal104_result_20261111.md)。

## 失败模式

- corrected gate 消除了 Goal88 的 path 退化，但 PPO 增量仍然只有 `+2/120` 左右；Goal92 的更新调度 screen 失败，低噪声探索没有证明是主瓶颈。[Goal90](../../../doc/goals/goal90_result_20261111.md)、[Goal92](../../../doc/goals/goal92_result_20261111.md)。
- Goal95 虽然成功安装了监督残差先验，但 1-seed screen 仍失败；B20 失败同时出现 authority-limited 签名和动作贴边，但审计不能证明限幅是唯一因果。[Goal95](../../../doc/goals/goal95_result_20261111.md)、[Goal103](../../../doc/goals/goal103_result_20261111.md)。

## 保留项

- 保留 corrected gate 的 `PG10_3` 首选 profile：它让 PPO 增量不再付出 path 代价；保留 ALOS/BC-only 配对和 residual dose-response 证据，避免把 BC 残差放大误判成 PPO 学习。[Goal90](../../../doc/goals/goal90_result_20261111.md)、[Goal101](../../../doc/goals/goal101_result_20261111.md)、[Goal102](../../../doc/goals/goal102_result_20261111.md)。
- 保留“动作参数化必须单独审计”的结论：B20 的大残差经常进入执行器边界，成功/失败不能只靠是否贴边解释。[Goal103](../../../doc/goals/goal103_result_20261111.md)、[Goal104](../../../doc/goals/goal104_result_20261111.md)。

## 开放问题

- PPO 增量弱、SAC 尚未同协议对照，且 pitch/纵向权限可能比总残差幅度更关键；下一阶段进入 terminal reward/credit、pitch tracking、constant bias 和课程学习。入口：[Goal107](../../../doc/goals/goal107_result_20261111.md)、[Goal113](../../../doc/goals/goal113_result_20261111.md)。
