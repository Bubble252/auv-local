# Goal91 结果：低噪声没有放大有效残差，噪声不是主瓶颈

**日期**：2026-11-11<br>
**状态**：`NOISE_NOT_PRIMARY_BOTTLENECK / SCREEN_ONLY / HELDOUT_CLOSED`<br>
**上游**：Goal90 `PASS_RL_GAIN_WEAK`、Goal89 gate-scope 审计<br>
**性质**：只改 PPO `init_noise_std`；固定 PG10_3 corrected gate、BC、scale、reward、terminal、success、goal radius 和 dev40。

## 1. 结论

Goal90 显示 PPO 确定性残差约 `0.014–0.021`，训练噪声 std 约 `0.10`，
噪声/信号约 `5.3×`。Goal91 预注册了 `0.03/0.05` 两个低噪声 arm：

| arm | noise std | default | strict125 | deterministic residual |
|---|---:|---:|---:|---:|
| `N03` | 0.03 | 31/31/31 | 19/20/19 | 0.0185 / 0.0262 / 0.0094 |
| `N05` | 0.05 | 31/31/31 | 20/20/19 | 0.0142 / 0.0279 / 0.0158 |
| `N10` | 0.10 | 31/31/31 | 20/20/19 | 0.0142 / 0.0206 / 0.0143 |

结果：

- `N03` 比 `N10` 少 1 个 strict 成功；
- `N05` 与 `N10` 完全持平；
- 确定性残差没有稳定放大到 2×；
- path 均在 BC+0.01 m 内，timeout `0`。

因此 **H91-A 被证伪**：单纯降低探索噪声不能释放 PPO 的有效残差。
H91-B 只得到弱支持：低噪声没有造成系统性崩坏，但没有带来收益。

低噪声既没有让残差变大，也没有改善 success，说明 PPO 分支的瓶颈更可能是
**credit assignment / 更新调度 / reward 终端信号**，而不是探索噪声本身。
Goal88 SAC 预注册的启动条件仍未全部满足：PPO 已有弱正增益，且尚未证明
更新调度无效；因此不立即开 SAC。
