## 1. 结论先行

三个 SAC seed 都完成了 `1,000,448` transitions，manifest 显示
`action_interface=controller_gain`、`action_dim=2`、`direct_commands_active=false`、
`reference_speed_mps=1.2`、`speed_contract.ok=true`，训练阶段没有 NaN/Inf。

但正式 evaluation 暴露了预注册风险项：

- H3 zero 与 gain-residual policy 都出现地速超过 REMUS100 `2.5 m/s` 上限；
- default current10 地速峰值 `2.88 m/s`，current15 峰值 `3.31 m/s`；
- 超限不是 residual 引入的：zero 与 policy 的最大值和超限比例几乎相同；
- 按 Goal162 文档，出现 `>2.5 m/s` 应判 `INVALID_SPEED_CONTRACT`，因此本次
  不能把结果写成普通 Gate `FAIL`，也不能据此启动 PPO/REDQ/DroQ 对照。

在速度契约之外，gain residual 有一个可解释的**局部分方向信号**：current10
strict125 从 `57/120` 到 `64/120`，current15 从 `66/120` 到 `74/120`；但
current10 default 只有 `90/120 -> 92/120`，未达到预注册 `+4/120`。机制分析显示
它主要是一个 near-goal 固定增益/俯仰增益，而不是 signed-error 反馈。

## 4. 速度包线审计

当前 evaluation 使用 rich trace 的 `ground_velocity_body_mps` 计算地速。超限比例和峰值：

| radius | level | zero max | policy max | zero over 2.5 | policy over 2.5 |
|---|---|---:|---:|---:|---:|
| default | nominal | 2.563 | 2.562 | 0.96% | 0.96% |
| default | current07 | 2.700 | 2.700 | 3.44% | 3.43% |
| default | current10 | 2.879 | 2.879 | 7.20% | 7.20% |
| default | current15 | 3.308 | 3.308 | 14.68% | 14.70% |
| strict125 | current10 | 2.879 | 2.879 | 7.53% | 7.51% |
| strict125 | current15 | 3.308 | 3.308 | 15.08% | 15.06% |

典型峰值出现在 current10 seed 40、step 1093：goal distance `18.7 m`，
`command_physical` speed `1.08 m/s`，实际 ground body velocity
`[2.87, -0.20, -0.11] m/s`，`nu` 约 `[2.27, -0.20, -0.05]`。这不是单步尖峰：
current15 有 40 个以上 episode seed 出现过 sustained overspeed，因此不是一次
采样 outlier，也不是 gain residual 打开后才出现。

结论：`speed_contract.ok=true` 只验证了配置层面的
`reference + current + variation` 上界，没有验证闭环控制器的积分、转向瞬态和
plant mismatch。Goal162 的 evaluation 契约应判 `INVALID_SPEED_CONTRACT`。

课程代码复核：`C6` 已是 `0.90–2.50 m/s`，`CurriculumStageSpec` 拒绝超过
`2.5 m/s` 的上界，sampler 逐 episode 保证
`speed + current + variation <= 2.5`；相关测试 `28 passed`。因此不能把本问题归因于
课程漏掉速度上限，也不能通过在课程中再加入一个更大速度范围来绕过。

## 5. 机制：near-goal 固定增益，而非 signed-error 调度

在 current10/default 的 policy trace 中：

- `>10 m` 的 applied gain delta 接近 0；`<=2 m` 的 heading/pitch abs mean 约
  `0.64/1.14`；`2–10 m` 约 `0.30/0.46`；
- 三个 seed 的 action saturation（`|a| >= 0.95`）约 `50–62%`；
- `heading delta vs signed lateral` 的相关性约 `+0.03/-0.13/-0.12`；
- `pitch delta vs signed vertical` 的相关性约 `+0.04/+0.12/-0.06`；
- `pitch delta vs goal distance` 约 `-0.29/-0.50/-0.22`。

这说明 residual 学到的不是“误差正负决定增益方向”，而是 gate 触发的近端
pitch gain 提升；它能把部分终止平面 miss 推入 success，但没有稳定修正
signed 横向/纵向误差。另一个实现事实是 SAC 的动作已在 `[-1,1]`，wrapper 再做
一次 `tanh`，所以实际可达的物理增益残差只有配置边界的约 `76.2%`；这属于后续
参数化设计问题，不在本 Gate 中事后修改。

## 7. 为什么现在不换 SAC/PPO/REDQ/DroQ

本次不是“residual 完全没有学”：near-goal 增益已经打开了，而且 strict125 有
稳定 `+7/120`；问题是：

1. 速度包线先失效，所有算法比较都失去共同的安全前提；
2. gain residual 主要是固定近端增益，不是 signed-error 反馈；
3. default current10 的效应仍小于 Gate，没有证据说这是探索/样本效率不足；
4. 因此应先做速度环/包线审计和控制器修正，再讨论 RL 算法族或更大预算。
